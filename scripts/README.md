# Scripts — Автоматизация и валидация

Набор скриптов для проверки консистентности данных в проекте training-brain.

---

## 📋 Доступные скрипты

### `validate-exercises.py`

**Назначение:** Проверяет все файлы `week-N.md` на соответствие библиотеке упражнений.

**Что проверяет:**
- Названия упражнений совпадают с `knowledge-base/exercises/exercise-library.md` посимвольно
- Упражнения существуют в библиотеке
- Находит похожие названия и предлагает исправления

**Использование:**

```bash
# Простая проверка
python scripts/validate-exercises.py

# Или из корня проекта
python -m scripts.validate-exercises
```

**Пример вывода:**

```
🏋️  Валидатор упражнений training-brain

✅ Загружено упражнений: 127

🔍 Найдено файлов для проверки: 12

⚠️  Найдено проблем: 8

📄 clients/dmitry-mukhin/mesocycle-1/week-2.md
  ⚠️  Строка 45: 'Болгарские сплит-приседы'
     💡 Возможно имелось в виду: 'Болгарские сплит приседания'
  ⚠️  Строка 78: 'Разгибания трицепса на канате'
     💡 Возможно имелось в виду: 'Разгибание рук на верхнем блоке с канатом'

📄 clients/dmitry-mukhin/mesocycle-1/week-3.md
  ⚠️  Строка 52: 'Румынская тяга'
     💡 Возможно имелось в виду: 'Румынская тяга со штангой'

📊 Статистика:
   - Неточное название (есть похожее): 7
   - Не найдено в библиотеке: 1
```

**Когда запускать:**
- Перед коммитом изменений в `week-N.md`
- После добавления новых упражнений в библиотеку
- Периодически (раз в неделю) для аудита старых файлов
- В CI/CD пайплайне (возвращает код ошибки при проблемах)

**Требования:**
- Python 3.7+
- Стандартная библиотека (нет внешних зависимостей)

## 💡 Как добавить новый скрипт

1. Создай файл `scripts/your-script.py`
2. Добавь shebang: `#!/usr/bin/env python3`
3. Добавь docstring с описанием
4. Обнови этот README
5. Используй `Path` из `pathlib` для работы с путями
6. Возвращай код ошибки через `sys.exit(1)` при проблемах

## 🔧 Интеграция с CI/CD

Пример для GitHub Actions:

```yaml
name: Validate Exercises

on: [push, pull_request]

jobs:
  validate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-python@v4
        with:
          python-version: '3.10'
      - run: python scripts/validate-exercises.py
```
