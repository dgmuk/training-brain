# Scripts — Автоматизация и валидация

Набор скриптов для проверки консистентности данных в проекте training-brain.

---

## 📋 Доступные скрипты

### `validate-exercises.py`

**Назначение:** Проверяет все файлы `week-N.md` на соответствие библиотеке упражнений.

**Что проверяет:**
- Названия упражнений совпадают с `knowledge-base/exercises/exercise-library.md` посимвольно
- Упражнения существуют в библиотеке
- Находит похожие названия и предлагает исправления

## 📖 Как работает валидатор

### Шаг 1: Загрузка библиотеки упражнений

Валидатор читает файл `knowledge-base/exercises/exercise-library.md` и извлекает:
- Названия всех упражнений (заголовки `### Название упражнения`)
- Ссылки на видео
- Группы мышц (разделы `## Грудные`, `## Спина`, и т.д.)

```python
# Пример: в библиотеке найдено
### Болгарские сплит приседания
[Видео](https://youtube.com/shorts/MagGM_X8d4M)
```

Валидатор сохраняет это как каноническое название: **"Болгарские сплит приседания"**

### Шаг 2: Поиск всех файлов week-N.md

Валидатор рекурсивно ищет все файлы с паттерном `week-*.md` в папке `clients/`:

```
clients/
├── dmitry-mukhin/
│   └── mesocycle-1/
│       ├── week-1.md ✓
│       ├── week-2.md ✓
│       ├── week-3.md ✓
│       └── week-4.md ✓
├── nikita-zaharov/
│   └── mesocycle-1/
│       └── program/
│           ├── week-1.md ✓
│           └── week-2.md ✓
```

### Шаг 3: Парсинг упражнений из каждого файла

В каждом `week-N.md` валидатор находит упражнения по заголовкам третьего уровня:

```markdown
### Болгарские сплит-приседы    ← находит это название
[Видео](...)
- 3 x 12-15 • 20/20/20 кг
```

Валидатор **игнорирует** служебные заголовки:
- `### � Статистика сессии`
- Любые заголовки со словом "Статистика"

### Шаг 4: Сравнение с библиотекой

Для каждого найденного упражнения валидатор проверяет:

1. **Точное совпадение (регистронезависимое):**
   - Упражнение: `"Болгарские сплит-приседы"`
   - Библиотека: `"болгарские сплит приседания"`
   - Результат: ❌ Не совпадает (дефис вместо пробела)

2. **Поиск похожих названий:**
   - Если точного совпадения нет, ищет упражнения, где одно название содержится в другом
   - `"сплит-приседы"` содержится в `"Болгарские сплит приседания"`
   - Результат: 💡 Предложение исправления

3. **Полное отсутствие:**
   - Если похожих не найдено
   - Результат: 🔴 Упражнение не найдено в библиотеке

### Шаг 5: Формирование отчета

Валидатор группирует проблемы по файлам и выводит:

```
📄 clients/dmitry-mukhin/mesocycle-1/week-2.md
  ⚠️  Строка 179: 'Болгарские сплит-приседы'
     💡 Возможно имелось в виду: 'Болгарские сплит приседания'
```

Где:
- `⚠️` = неточное название (есть похожее в библиотеке)
- `🔴` = упражнение вообще не найдено
- `Строка 179` = номер строки в файле для быстрого поиска
- `💡 Возможно имелось в виду` = предложение правильного названия

## 📊 Типы проблем

### 1. Неточное название (⚠️)

**Что это:** Упражнение есть в библиотеке, но название написано по-другому.

**Примеры:**
- ❌ `"Румынская тяга"` → ✅ `"Румынская тяга со штангой"`
- ❌ `"Жим ногами"` → ✅ `"Жим ногами в тренажере"`
- ❌ `"Махи в наклоне"` → ✅ `"Махи с гантелями в наклоне"`
- ❌ `"Болгарские сплит-приседы"` → ✅ `"Болгарские сплит приседания"`

**Причины:**
- Сокращенное название
- Опущено уточнение (со штангой, в тренажере, с гантелями)
- Дефис вместо пробела
- Множественное/единственное число

**Как исправить:**
1. Открой файл `week-N.md`
2. Найди строку с упражнением (номер указан в отчете)
3. Замени название на предложенное валидатором
4. Проверь что видео-ссылка тоже из библиотеки

### 2. Не найдено в библиотеке (🔴)

**Что это:** Упражнение отсутствует в `exercise-library.md`.

**Примеры:**
- `"Face Pulls"` (есть "Махи в наклоне", но не Face Pulls)
- `"Сгибания ног в тренажёре"` (есть "Сгибание ног в тренажере лежа")
- `"Жим штанги лёжа"` (есть "Жим штанги лежа на горизонтальной скамье")

**Причины:**
- Упражнение действительно отсутствует в библиотеке
- Используется бытовое/сленговое название
- Ошибка в написании (лёжа вместо лежа)

**Как исправить:**

**Вариант А: Добавить в библиотеку**
1. Открой `knowledge-base/exercises/exercise-library.md`
2. Найди нужный раздел (грудные, спина, ноги и т.д.)
3. Добавь упражнение в формате:
   ```markdown
   ### Точное название упражнения
   [Видео](https://youtube.com/...)
   ```
4. Запусти валидатор снова — проблема исчезнет

**Вариант Б: Заменить на существующее**
1. Открой `exercise-library.md` и найди похожее упражнение
2. В `week-N.md` замени название на существующее из библиотеки

## 💻 Технические детали

**Требования:**
- Python 3.7+
- Стандартная библиотека (нет внешних зависимостей)

**Код возврата:**
- `0` = все проверки прошли, проблем нет
- `1` = найдены проблемы или ошибка

**Когда запускать:**
- Перед коммитом изменений в `week-N.md`
- После добавления новых упражнений в библиотеку
- Периодически (раз в неделю) для аудита старых файлов
- В CI/CD пайплайне (возвращает код ошибки при проблемах)

## 🔧 Интеграция с CI/CD

Пример для GitHub Actions:

```yaml
name: Validate Exercises

on: [push, pull_request]

jobs:
  validate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-python@v4
        with:
          python-version: '3.10'
      - run: python scripts/validate-exercises.py
```
