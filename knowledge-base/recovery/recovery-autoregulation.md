# Авторегуляция: если X, то в week-N делай Y

> [[index]] | [[../index]] | [[../../CLAUDE.md]]

---

## Саммари

[[recovery-markers]] описывает *что* смотреть. Этот документ: **конкретные правки программы** на следующей неделе (Схема Б) и внутри недели, если клиент пишет в середине. Не отменяет плановый делоад: это слой поверх.

---

## Входные сигналы (минимум)

Из дневника / чек-ина:

| Сигнал | Порог «жёлтый» | Порог «красный» |
|--------|----------------|-----------------|
| Энергия | 5/10 средняя за неделю | ≤4/10 на 2+ тренировках |
| RPE сессии | ≥8 при плановом RIR 2–3 | ≥9 и веса падают |
| ЧСС покоя утром | +5 уд/мин к базе 3 дня | +8–10 и симптомы |
| HRV (если ведёт) | −10–20% к базе | −20%+ |
| DOMS | 48–72 ч мешает технике | Боль «суставная» / DOMS 4+ дня |
| Сон | <6.5 ч среднее | <6 ч 4+ ночи |
| Attendance | пропуск 1 сессии | 2+ подряд |
| Заметки | «тяжело / нет мотивации» | боль сустава, головокружение |

База ЧСС/HRV: 7–14 дней спокойных измерений, иначе ориентир субъективный.

---

## Матрица решений (Схема Б → week N+1)

Считай **число жёлтых и красных** за прошедшую неделю.

| Ситуация | Действие на week N+1 |
|----------|----------------------|
| 0–1 жёлтый, 0 красных | Стандартная прогрессия [[../methodology/progression-rules]] |
| 2+ жёлтых, 0 красных | **Hold:** веса как на прошлой неделе или +0; объём −1 подход с крупных; RIR +0.5–1 |
| 1 красный (энергия/сон/RPE) | **Ease:** объём −20–30% (к MEV), веса −5–10% на компаундах, RIR 3–4; без интенсификации |
| 2+ красных **или** красный + падение весов 2 нед | **Внеплановый делоад 5–7 дней** по [[deload-protocols]] (MV, 50–60% ощущения) |
| Суставная боль (не мышцы) | Не прогрессия: замена упражнения + [[../contraindications/index]] / tendinopathy |
| Болезнь (температура, ОРВИ) | См. ниже microcycle illness |
| Пропуск 2–3 тренировок | [[../methodology/adherence-protocols]]: возврат 80% весов |
| Пропуск ≥1 недели | Восстановительная неделя −40% объём, −10–15% веса |

### Формулировки для клиента (коротко)

- Hold: «На этой неделе закрепляем веса, не добавляем подходы, цель техника и RIR с запасом.»  
- Ease: «Немного разгружаем объём, веса чуть ниже, восстанавливаемся без потери навыка.»  
- Deload: «Разгрузочная неделя, лёгкие веса, выходим свежими в следующий блок.»

Без длинных тире в week-N (ПРАВИЛО №1 CLAUDE).

## Правки внутри текущей недели (если пишет mid-week)

| Сообщение | Сегодня / завтра |
|-----------|------------------|
| Плохо спал 1 ночь | Тренировку можно, RIR +1, можно −1 подход |
| ЧСС/HRV красный утром | Лёгкая сессия или перенос тяжёлого компаунда |
| Начинающаяся простуда без температуры | Upper light / техника, не max lower |
| Температура / ломота | Отмена силовой, ходьба по самочувствию |
| Острая боль в суставе | Стоп движения, не «перетерпеть подход» |

## Microcycle: болезнь

```
День 0–2 температура / сильная слабость: 0 силовых
Симптомы только выше шеи, энергия ок: 50–70% объёма, RIR 4, 1–2 сессии
Возврат после 3–7 дней болезни: первая неделя −30–40% объёма, веса −10%
После 7+ дней: как короткий return-after-break, не прыгать в пик мезо
```

---

## Microcycle: разъезды / нет зала

1. Сохранить **паттерны**, не тоннаж: squat/hinge/push/pull/carry из library (гантели, band, bodyweight).  
2. 2–4 сессии по 30–40 мин, RIR 2–3.  
3. По возвращении: 1 неделя 80–90% предыдущих зальных весов, не PR-неделя.  
4. В overview пометить «travel week», не считать как полноценный пик объёма.

Дом-замены: [[../exercises/home-equipment]].

---

## Связь с планом мезо

| Неделя мезо | Авторегуляция |
|-------------|---------------|
| 1–2 | Легче hold, чем early deload |
| 3–4 | 2+ жёлтых: лучше hold/ease, чем форсировать RIR 0 |
| 5 делоад | Уже разгрузка; не добавляй объём «раз всё равно легко» если флаги были |
| После внепланового делоада | Следующая = как нед 1–2 по RIR, не прыжок в бывшую нед 4 |

## Что писать в mesocycle overview (для тренера)

```markdown
### Авторегуляция нед N
Сигналы: энергия 4/10, сон 6 ч, RPE 8.5
Решение: Ease (−25% объёма, RIR 3–4)
```

В client week-N: коротко в «По чек-ину» / «Объём недели», без таблицы на 20 строк.
