## Иерархия

```
МАКРОЦИКЛ (3–12 мес)
  └─ МЕЗОЦИКЛ (4–6 нед)
       └─ МИКРОЦИКЛ (1 нед)
            └─ ТРЕНИРОВОЧНЫЙ ДЕНЬ
```

## Когда строится макроцикл

**Всегда.** Даже если клиент пришёл с целью «3 месяца» — это макроцикл из 3 мезоциклов. Макроцикл — это любой план, объединяющий несколько мезоциклов в одну стратегию.

Без макроцикла каждый мезоцикл будет жить сам по себе, а долгосрочная прогрессия не сложится.
