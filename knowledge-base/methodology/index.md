## Принципы методологии

1. **Сначала безопасность.** Любая программа начинается с проверки противопоказаний и допусков, не с «крутости» плана.
2. **Калибруй прежде чем нагружать.** Без точной стартовой точки прогрессия — это гадание.
3. **Объём считай дробно.** Прямой счёт всегда обманывает по малым группам.
4. **Делоад непреложен.** Пятая неделя — не опция.
5. **Программа меняется по данным, не по календарю.** Корректировки строятся на чек-инах клиента, не на «прошла неделя — поменяем».
