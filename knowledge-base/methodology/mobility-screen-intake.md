# Скрининг подвижности на приёме (intake screen)

> [[index]] | [[../index]] | [[../../CLAUDE.md]]

---

## Саммари

Короткий экран из 4 паттернов перед калибровкой. Цель не поставить диагноз, а решить, какие упражнения **безопасны на нед 1**, какие заменить, какие отложить. Результат: зелёный / жёлтый / красный по каждому паттерну, запись в `profile.md`.

Тренер не лечит. Красный + боль = врач, см. [[../contraindications/medical-clearance]].

---

## Когда проводить

| Ситуация | Скрининг |
|----------|----------|
| Новый клиент, Схема А | Обязательно до или в рамках нед 1 |
| Перерыв >3 мес | Обязательно |
| Смена зала / боль в анамнезе | Обязательно |
| Активный клиент без жалоб | По желанию раз в 2–3 мезо |
| Острая боль сейчас | Не экран, к врачу |

---

## 4 теста (5–8 минут)

Клиент без отягощения или с очень лёгким весом. 5–8 медленных повторений. Смотри боль, контроль, компенсацию.

### 1. Присед (bodyweight squat)

**Смотри:** глубина (параллель?), колени внутрь, пятки отрыв, сильный наклон корпуса, боль в колене/пояснице.

| Цвет | Критерий | Следствие для программы |
|------|----------|-------------------------|
| 🟢 | Параллель или ниже, контроль, без боли | Присед / goblet / фронтальный ок |
| 🟡 | Выше параллели, пятки / вальгус, без острой боли | Гоблет, бокс-присед, жим ногами; учить глубину |
| 🔴 | Боль в колене/пояснице, потеря баланса | Убрать осевой присед, [[../contraindications/knees]] / lower-back |

### 2. Hinge (наклон с прямой спиной / reach to mid-shin)

**Смотри:** сгиб в тазу vs скругление поясницы, боль в низу спины.

| Цвет | Следствие |
|------|-----------|
| 🟢 | RDL, становая с пола по уровню |
| 🟡 | RDL с короткой амплитудой, hyper, glute bridge; становую с пола отложить |
| 🔴 | Без осевого hinge со штангой, [[../contraindications/lower-back]] |

### 3. Overhead (руки вверх стоя, можно у стены)

**Смотри:** поясничный прогиб взамен сгибания плеч, асимметрия, боль в плече.

| Цвет | Следствие |
|------|-----------|
| 🟢 | Жим стоя/сидя в программе ок |
| 🟡 | Жим сидя, нейтральный хват, landmine/тренажёр; не из-за головы |
| 🔴 | Вертикальный жим убрать, [[../contraindications/shoulders]] |

### 4. Push (отжимание от пола или от стены)

**Смотри:** провал поясницы, лопатки, боль в плече/запястье, асимметрия.

| Цвет | Следствие |
|------|-----------|
| 🟢 | Жим лёжа / отжимания по плану |
| 🟡 | Жим в тренажёре, гантели, ограниченная амплитуда |
| 🔴 | Горизонтальный жим только после допуска/модификаций shoulders |

---

## Алгоритм после экрана

```
1. Записать 4 цвета в profile.md (блок «Скрининг паттернов»)
2. Любой 🔴 + боль → medical-clearance / соответствующий contraindication
3. Любой 🟡 → заменить упражнение через exercise-tags (тот же primary, joints без красной зоны, sfr high)
4. Все 🟢 → стандартная калибровка [[weight-calibration-week-1]]
5. В week-1 рекомендации дня: 1 предложение про ограничения амплитуды если был 🟡
```

### Шаблон в profile.md

```markdown
### Скрининг паттернов (дата)
| Паттерн | Цвет | Заметка |
|---------|------|---------|
| Присед | 🟡 | Пятки, глубина до параллели |
| Hinge | 🟢 | |
| Overhead | 🟡 | Прогиб, жать сидя |
| Push | 🟢 | |

Запреты на старт: присед со штангой на спине, жим стоя.
Предпочтения: гоблет, жим сидя нейтральный хват, RDL.
```

## Связь с тегами упражнений

При 🟡/🔴 фильтр по [[../exercises/exercise-tags]]:

- колено 🔴/🟡 → избегать pattern squat с joints=knee,lumbar без опоры; брать leg_press, lunge с контролем
- lumbar 🔴 → убрать hinge/squat с joints=lumbar
- shoulder 🔴 → убрать vertical_press, dip; брать machine press, neutral

Имена всё равно только из [[../exercises/exercise-library]].

---

## Чего экран не делает

- Не заменяет врача и визуализацию
- Не «FMS score» и не прогноз травм
- Не повод навсегда запретить присед: пересматривай через 4–8 недель
