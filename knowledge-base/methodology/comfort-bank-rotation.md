# Comfort Bank Rotation (CBR)

> [[index]] | [[../index]] | [[../../CLAUDE.md]]

---

## Для кого

Клиенты, которым **не нужна** стандартная история «каждую неделю тяжелее / ближе к отказу»:

- не любят сильную нагрузку и большие веса;
- цель скорее тонус, привычка, самочувствие, разнообразие, а не max гипертрофия или сила;
- комфортно на **RIR 3–4**, ниже **RIR 2** опускаться нельзя;
- уже есть готовый блок тренировок (банк недель), на котором строится дальнейшая работа.

**Референс-клиент:** `ekaterina-funtova` (Фунтова Екатерина).

Если в `profile.md` указано:

```yaml
programming_mode: comfort_bank
```

то при Схеме Б **этот документ перекрывает** стандартные [[progression-rules]] по повышению веса и снижению RIR. Остальные правила (library, формат week-N, adherence, сигналы клиента) остаются в силе.

---

## Главная идея

| Стандартный клиент | Comfort Bank |
|--------------------|--------------|
| Прогрессия через вес и RIR 3→2→1 | Веса в основном **удерживаем** |
| Разнообразие через изоляцию A/B | Разнообразие через **ротацию целых недель-шаблонов** |
| Мезо 5 нед с пиком и делоадом | Цикл 4+ недель из банка, без «пика до отказа» |
| Успех = рост тоннажа | Успех = adherence + комфорт + новизна |

**Рычаг новизны №1:** какая неделя из банка сейчас в плане.  
**Рычаг новизны №2:** точечная замена 1–2 упражнений внутри дня на аналог из другой недели банка (тот же паттерн).  
**Рычаг нагрузки:** почти всегда hold; мелкий шаг веса только если клиент явно «очень легко» и нет жалоб на дискомфорт.

## Банк недель (Week Bank)

Банк, это 3–4 (или больше) уже проверенных недель с реальными весами клиента.

| Поле | Описание |
|------|----------|
| **Template ID** | `W1`, `W2`, `W3`, `W4` (соответствуют исходным неделям 1–4) |
| **Файл-источник** | `mesocycle-1/week-1.md` … `week-4.md` (или `bank/W1.md` если вынесено отдельно) |
| **Сплит** | Как в банке (у Фунтовой: 3 full-body / mixed дня) |
| **Базовые веса** | Рабочие веса из шаблона, это «комфортный якорь» |

В `mesocycle-N/overview.md` обязательно блок:

```markdown
## 🏦 Банк недель (Comfort Bank)

**Режим:** comfort_bank
**Целевой RIR:** 3–4 (пол: никогда не ниже 2)
**Политика веса:** hold by default

| ID | Источник | Акцент (кратко) | Статус |
|----|----------|-----------------|--------|
| W1 | week-1.md | ... | bank |
| W2 | week-2.md | ... | bank |
| W3 | week-3.md | ... | bank |
| W4 | week-4.md | ... | bank |
```

## Календарь ротации

### Базовый цикл (порядок банка)

```
Непрерывная неделя N:   W1 → W2 → W3 → W4 → (повтор)
```

### Цикл с перетасовкой (новизна без новых весов)

После 1–2 полных проходов банка меняем **порядок**, не веса:

```
Проход 1: W1 → W2 → W3 → W4
Проход 2: W2 → W4 → W1 → W3
Проход 3: W3 → W1 → W4 → W2
```

Правило: соседние недели цикла не должны быть «почти одинаковыми» по составу, если в банке есть более контрастная пара (смотри overview клиента).

### Точечный микс (не чаще 1 раза в 2 недели)

Если клиентка пишет «хочу что-то новое», но полный шаблон устраивает:

1. Оставь каркас текущей недели банка (порядок дней и якоря).
2. Замени **1–2** изоляции / вторичных движения на аналоги из **другой** недели банка (тот же primary/pattern, имена только из [[../exercises/exercise-library]]).
3. В `**Что меняем:**` пометь: «ротация из банка, комфорт».

Не собирай день с нуля из случайных упражнений, если в банке уже есть рабочие варианты.

## Правила нагрузки (перекрывают standard progression)

### Целевой RIR

| Параметр | Значение |
|----------|----------|
| План в week-N | **RIR 3–4** на всех рабочих подходах |
| Пол (hard floor) | **RIR 2** — ниже не программировать никогда |
| Интенсификация | **Запрещена** (дроп-сеты, rest-pause, myo-reps, RIR 0–1) |

### Решение по факту прошлой недели

| Факт | Действие на следующую выдачу того же шаблона / упражнения |
|------|-----------------------------------------------------------|
| RIR 3–4, повторы в плане, без жалоб | **Hold** вес и повторы |
| RIR ≥ 5 или «очень легко», техника ок | **По умолчанию hold** + новизна ротацией. Повышение веса только если тренер/клиент ок: мелкий шаг (+1–2.5 кг или 1 плитка), **не** гнать RIR к 2 |
| RIR = 2 ровно, все повторы | Hold или −1 плитка / −2.5 кг на след. раз; в рекомендации дня напомнить про запас |
| RIR < 2, срыв повторов, «тяжело», техника плывёт | **−5–10%** веса или упростить вариант из банка; не повышать объём |
| Боль в суставе (не DOMS) | Замена из банка / library, без прогрессии на этом движении |
| «Скучно» / просьба новизны | Сменить template ID или 1–2 упражнения, веса hold |

### Объём

- Не наращивать подходы «к MRV» по классическому мезо.
- Объём ≈ объём банка (допустимо ±1 подход на изоляцию при восстановлении).
- Не удваивать пропущенный день.

### «Лёгкая» неделя (вместо классического делоада)

Не обязательна каждые 5 недель. Ставить когда:

- 2+ недели подряд энергия ≤5/10 или DOMS мешает быту;
- adherence watch/talk;
- явная просьба «полегче».

Формат лёгкой недели:

- тот же template ID (или самый любимый из банка);
- веса **−10–15%** или те же веса при RIR 4–5;
- можно убрать 1 изоляцию в каждом дне;
- без морали в тексте клиенту.

## Алгоритм Схемы Б для comfort_bank

```
1. Идентифицировать клиента, открыть profile + mesocycle overview
2. Убедиться: programming_mode: comfort_bank
3. Считать реестр сигналов + adherence (как обычно)
4. Определить следующий Template ID по календарю ротации overview
5. Скопировать каркас недели из банка (упражнения, сеты, повторы, веса-якоря)
6. Применить корректировки весов ТОЛЬКО по таблице hold/ease выше
7. При необходимости точечный микс 1–2 упражнений из другого W*
8. Записать week-(N+1).md в канон-формате (День N, разминка/заминка, альтернативы)
9. В overview: какой template выдан, hold/ease, сигналы
10. В ответе тренеру: явно «режим comfort_bank, прогрессия standard НЕ применялась»
```

### Чего не делать

- Не снижать плановый RIR до 1–2 «потому что неделя 4 мезо».
- Не поднимать вес только потому что «прошла неделя».
- Не строить 5-недельную пирамиду MEV→MRV, если профиль comfort_bank.
- Не игнорировать просьбу «легче» ради «эффективности».
- Не выдумывать упражнения вне library; банк + library.

## Что писать клиенту

Тон: спокойный, без давления «надо расти».

В `**Рекомендация:**` и `**Контекст недели:**`:

- комфортный запас 3–4 повтора;
- если чувствуешь отказ раньше, снижай вес сразу;
- новизна через другой набор движений недели, не через героизм.

В `**Резюме прошлой недели:**` процент попадания в план всё равно полезен, но формулировки про «было легко → добавили вес» заменяй на «держим комфорт / чуть обновили состав».

## Связь с ротацией изоляции A/B

Классическая [[isolation-rotation]] для comfort_bank **вторична**.

- Режим в overview: `comfort_bank` (не `default` A/B).
- Если нужен мини-A/B, только внутри слотов банка (упражнение из W1 vs из W3 на ту же группу).
- Якорные движения банка можно слегка чередовать между шаблонами (у Фунтовой присед со штангой / Смит / goblet уже разнесены по неделям).

## Чеклист онбординга comfort_bank клиента

1. `client_id` латиницей, строка в [[../../clients/index]]
2. `profile.md` с `programming_mode: comfort_bank` и жёсткими правилами RIR
3. Банк 3–4 недель с весами в `mesocycle-1/week-1..N.md`
4. `mesocycle-1/overview.md` с таблицей банка и календарём ротации
5. `macrocycle/strategy.md` без обещания силовых пиков
6. Следующая неделя = continuous week после последней bank-недели
