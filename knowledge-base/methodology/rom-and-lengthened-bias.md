# ROM и lengthened bias

> [[index]] | [[../index]] | [[../../CLAUDE.md]]

---

## Саммари

Для гипертрофии упражнения с нагрузкой в **растянутой (длинной) позиции** мышцы часто дают сильный стимул. Полный безопасный ROM предпочтителен, но «полный любой ценой» при боли в суставе хуже контролируемой амплитуды. Lengthened partials и partials после отказа, это инструмент пиковых недель, не база для новичка.

---

## Термины

| Термин | Смысл |
|--------|--------|
| Полный ROM | Максимальная безопасная амплитуда без потери техники и без боли |
| Lengthened bias | Больше напряжения в растянутой части (низ разводки, низ сплит-приседа, верх тяги блока) |
| Shortened bias | Акцент на пиковом сокращении (ягодичный мост верх, сведение в бабочке) |
| Lengthened partials | Частичные повторения только в длинной позиции после отказа в полной амплитуде |

---

## Правила отбора упражнений

1. На каждую крупную группу в неделе желателен **хотя бы 1 lengthened-bias** паттерн.
2. Shortened-bias (мосты, пиковые сведения) дополняет, не заменяет lengthened.
3. При равном SFR предпочитай вариант с лучшим растяжением под контролем.
4. Имена только из [[../exercises/exercise-library]], фильтр по pattern/joints в [[../exercises/exercise-tags]].

### Примеры lengthened-bias (ориентиры)

| Группа | Паттерны / идеи |
|--------|-----------------|
| Грудные | Разводка, жим гантелей с глубоким низом, сведение с нижних/средних блоков |
| Широчайшие | Вертикальная тяга с полным подъёмом рук, пуловер |
| Бицепс бедра | Румынская тяга, сгибание ног (особенно сидя при доступности) |
| Ягодичные / сплит | Болгарские и выпады с контролируемой глубиной |
| Бицепс | Сгибания на наклонной / Скотта (длинная позиция) |
| Трицепс | Разгибания из-за головы |
| Дельты | Не жертвовать техникой ради «ниже», боль в impingement = стоп |

---

## Когда НЕ тянуть ROM

| Ситуация | Действие |
|----------|----------|
| Острая боль в суставе | Сократить амплитуду до безболевой, см. contraindications |
| Новичок, техника плывёт внизу | Укоротить 10–20% глубины, учить паттерн |
| Импиджмент плеча в низе жима | Ограничить глубину, сменить на тренажёр / нейтральный хват |
| Боль в пояснице в конце RDL | Укоротить ход, меньше веса, hinge из таза |
| После операции / допуск врача | Только разрешённая амплитуда |

Правило: **безболевой контролируемый ROM > теоретически полный ROM с болью.**

---

## Lengthened partials в программе

**Когда:** нед 3–4 мезо, изоляция, RIR 0, клиент средний+, техника стабильна.  
**Как:** отказ в полной амплитуде → 4–8 частичных только в длинной зоне.  
**Где не ставить:** новичок, делоад, калибровка, силовые тяжёлые компаунды, острый сустав.

Подробнее техники: [[intensification-techniques]].

---

## Формулировки в рекомендации дня

- `В разводке чувствуй растяжение внизу, без провала плеч вперёд.`
- `В болгарских опускайся до комфортной глубины, колено по носку, без отскока.`
- `В румынской тяге ход только пока спина нейтральна, не округляй низ ради глубины.`
