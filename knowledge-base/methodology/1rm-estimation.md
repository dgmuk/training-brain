# Оценка 1RM (одноповторного максимума)

> [[index]] | [[../index]] | [[../../CLAUDE.md]]

---

## Саммари

Тестирование истинного 1RM редко оправдано на практике: высокий риск травмы, плохая воспроизводимость, требует длительной разминки и пика формы. Для программирования достаточно **расчётной оценки 1RM** на основе подходов с повторениями — точность ±2–5% при 1–10 повторениях. Для 12+ повторений ошибка растёт. Альтернативный путь: оценка через RPE / RIR.

---

## Основные формулы

### Формула Brzycki (наиболее точна для 1–10 повторов)

```
1RM = вес / (1.0278 − 0.0278 × повторения)
```

### Формула Epley (хороша для 8+ повторов)

```
1RM = вес × (1 + 0.0333 × повторения)
```

### Усреднение

Для надёжности — посчитать обе формулы и взять среднее.

## Поправка на RIR (RPE-based 1RM)

Если подход выполнен **не до отказа**, формула:

```
1RM_оценка = вес / процент_от_1RM_при_(повт + RIR)
```

То есть «вес × N повт. с RIR=2» эквивалентен «вес × (N+2) повт. до отказа».

**Пример:**
Жим лёжа 80 кг × 8 повт. × RIR 2 = эквивалентно 80 кг × 10 повт. до отказа.
По таблице (10 повт.) → 80 / 0.74 = **108 кг 1RM**.

## Когда стоит делать прямой тест 1RM

Редко, но обоснованно:
- Подготовка к соревнованиям (за 1–2 нед до старта)
- Конец длинного силового мезоцикла (для сверки с планом)
- Атлет с большим стажем и стабильной техникой

**Никогда не делай тест 1RM:**
- В первые 4 недели работы с клиентом
- Если есть текущие боли в суставах
- При недосыпе / болезни / стрессе
- На новом или редко используемом упражнении
- У клиентов 50+ без специальной подготовки

## Альтернатива тесту 1RM: AMRAP

**AMRAP (As Many Reps As Possible)** — подход на максимум повторений с фиксированным весом.

- Безопаснее тест 1RM
- Даёт оценку и мышечной выносливости, и максимальной силы
- Применять с весом 70–80% от ожидаемого 1RM
- Останавливаться на чистой технике, не выжимать «грязный» подход
- Применять не чаще раза в 4–6 недель

---

## Применение в системе

### При приёме клиента

Если в анкете указано «жим 80 кг × 8 повт. × около RIR 2» — оцениваем 1RM ≈ 108 кг (см. пример выше).

Стартовые рабочие веса для программы:
- 8–12 RM ≈ 70–78% 1RM
- 12–15 RM ≈ 65–69% 1RM

### После Недели 1 калибровки

В калибровочной неделе клиент сообщает финальный «вес × повт. × RIR» по каждому упражнению.
По формуле получаем оценку 1RM → строим прогрессию для следующих недель ([[progression-rules]]).

## Чек-лист применения

```markdown
□ Использован вес из подхода с RIR ≤ 3 (не «легкий разминочный»)
□ Повторения в диапазоне 1–10 (для лучшей точности)
□ Учтён фактический RIR через таблицу RPE
□ Проверены 2 формулы (Brzycki + Epley) для надёжности
□ Округление до 2.5 кг (штанга) или 1 кг (гантели)
□ Результат внесён в profile.md
```
