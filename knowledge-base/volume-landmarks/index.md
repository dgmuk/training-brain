## Расшифровка терминов

| Термин | Определение |
|--------|-------------|
| **MV** (Maintenance Volume) | Минимум для удержания мышечной массы. Делоад-неделя. |
| **MEV** (Minimum Effective Volume) | Минимум для запуска роста. Старт мезоцикла. |
| **MAV** (Maximum Adaptive Volume) | Диапазон оптимального роста. Середина и пик мезоцикла. |
| **MRV** (Maximum Recoverable Volume) | Предел, после которого восстановление нарушается. Нельзя превышать. |

---

## Корректировки MRV

| Фактор | Коэффициент |
|--------|-------------|
| Новичок (< 1 года) | × 0.70 |
| Продвинутый (5+ лет) | × 1.20 |
| Сон < 6 ч/сут | × 0.85 |
| Сон 6–7 ч/сут | × 0.90 |
| Высокий стресс (работа, жизнь) | Стартовать с нижней MEV |
| Тяжёлый физический труд | × 0.85 |

**Пример расчёта MRV для груди:**
- Базовое MRV: 22 подхода
- Клиент — новичок: 22 × 0.70 = **15.4** → округляем до **15 подходов**
- Клиент — продвинутый, сон 6ч: 22 × 1.20 × 0.90 = **23.8** → **24 подходов**
