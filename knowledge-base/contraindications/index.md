# 🩺 Contraindications — Противопоказания

> [[../index]] | [[../../CLAUDE.md]]

Раздел описывает протоколы работы с клиентами, у которых есть **активные ограничения по здоровью**. Используется на этапе валидации анкеты ([[../methodology/intake-workflow]]) и при принятии решения о медицинском допуске.

---

## ⚠️ Главное правило

Тренер **не ставит диагнозы и не лечит**. При любых сомнениях клиент направляется к профильному специалисту. Программа строится только в рамках того, что разрешено врачом и не противоречит научным протоколам безопасности.

## Базовый чек-лист на этапе анкеты

```markdown
□ Возраст 50+ → проверить документ medical-clearance
□ Указаны ССЗ → cardiovascular
□ Указаны препараты, влияющие на ЧСС/давление → отметка в profile
□ Беременность / послеродовой период → отдельный протокол (вне раздела)
□ Любые операции последний год → уточнение у клиента / врач
□ Острые боли в момент анкеты → не стартовать, к врачу
□ Травмы суставов в анамнезе → соответствующий документ (lower-back / shoulders / knees)
□ Хронические заболевания (диабет, астма, щитовидка и т.д.) → отдельная заметка, более мягкий старт
```

## Принцип «3 уровней»

При любом ограничении вопрос решается на одном из трёх уровней:

### Уровень 1 — Можно тренироваться без оговорок
Ограничение в анамнезе, но в данный момент не активно (например, давняя травма, прошедшая полностью). Действие: пометка в profile, мониторинг.

### Уровень 2 — Можно с модификациями
Ограничение есть, но не блокирует движение полностью. Действие: список запрещённых движений, замены упражнений, более низкая интенсивность, более длинная разминка, дополнительные изоляции для проблемной зоны.

### Уровень 3 — Нельзя без медицинского допуска
Острая боль, неустановленный диагноз, хроническое заболевание, требующее контроля. Действие: остановить программирование, направить к врачу, ждать заключение.

```markdown
### Активные ограничения

| Зона | Уровень | Статус | Протокол |
|------|---------|--------|----------|
| Плечи | 2 | ⚠️ Контроль | [[../knowledge-base/contraindications/shoulders]] |

### Запрещённые движения
- Жим из-за головы
- Классический присед со штангой
- (...)
```
