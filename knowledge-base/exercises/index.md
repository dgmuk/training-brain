# 📁 Упражнения — Индекс раздела

> [[../index]] | [[../../CLAUDE.md]]

Раздел с канонической библиотекой упражнений и протоколами под разное оборудование.

---

## ⚠️ Главное правило раздела

Каноническая библиотека имён и видео-ссылок живёт в [[exercise-library]]. Имена упражнений в любом `week-N.md` берутся из неё буква-в-букву. Не добавлять упражнения через этот индекс, только через [[exercise-library]] по формату описанному в самом файле.

---

## Документы раздела

| Документ | Назначение |
|----------|-----------|
| [[exercise-library]] | Каноническая библиотека всех упражнений и видео-ссылок (источник правды имён) |
| [[exercise-tags]] | Теги: мышцы, паттерн, суставы, SFR, роль, оборудование (источник правды метаданных) |
| [[home-equipment]] | Каталог упражнений и сплитов под домашнее оборудование (гантели + турник + скамья) |

---

## Когда нужно куда идти

| Задача | Документ |
|--------|----------|
| Найти точное имя упражнения для week-N.md | [[exercise-library]] |
| Найти видео по упражнению | [[exercise-library]] |
| Фильтр по суставу / SFR / primary мышце | [[exercise-tags]] |
| Добавить новое упражнение в библиотеку | [[exercise-library]] + строка в [[exercise-tags]] |
| Подобрать упражнения под клиента дома | [[home-equipment]] |
| Заменить упражнение зала на домашнее | [[home-equipment]] (таблица замен) |
| Алгоритм отбора упражнений по SFR | [[../methodology/exercise-selection]] |
| Замены при травмах | [[../contraindications/index]] + joints в [[exercise-tags]] |
