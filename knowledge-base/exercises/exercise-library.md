# 🎬 Exercise Library — Каноническая библиотека упражнений

> [[index]] | [[../index]] | [[../../CLAUDE.md]]

Это **единственный источник правды** для названий упражнений и ссылок на видео. При построении любой недели тренировок имена упражнений берутся отсюда буква-в-букву, ссылки `[Видео](...)` подставляются из этого файла.

---

## 🚨 Правила работы с библиотекой

1. Имя упражнения в `week-N.md` должно совпадать с именем в библиотеке посимвольно, включая регистр и пунктуацию.
2. Если упражнения нет в библиотеке, не выдумывай ссылку, оставь только имя без `[Видео](...)`, и сообщи тренеру что нужно дополнить библиотеку.
3. Если в библиотеке несколько вариантов одного движения (например, Жим гантелей лёжа на горизонтальной и Жим гантелей на наклонной), используй точное имя нужного варианта.
4. Если ссылка в библиотеке пустая (плейсхолдер `https://...`), не подставляй её в week-N, оставь упражнение без видео.

---

## 📝 Формат записи

Каждое упражнение записано блоком:

```
### Точное имя упражнения
[Видео](https://youtu.be/...)
Техника: краткая заметка по технике, опционально.
Замечания: опционально, например для каких ограничений подходит.
```

При добавлении нового упражнения соблюдай эту структуру, иначе агент не сможет его найти.

## ➕ Как добавить новое упражнение

1. Найди подходящий раздел по группе мышц.
2. Добавь блок в формате:

```
### Точное имя упражнения
[Видео](https://реальная-ссылка)
Техника: опционально.
```

3. Используй точно такое же имя в любых программах, иначе агент не сможет связать упражнение со ссылкой.
4. После добавления упражнения в библиотеку оно становится доступно для использования в любой `week-N.md`.
