# Модели периодизации

> [[index]] | [[../index]] | [[../../CLAUDE.md]]

---

## Саммари

Периодизация — это стратегическое управление объёмом, интенсивностью и частотой тренировок во времени для максимизации адаптации и предотвращения перетренированности. Не существует универсальной лучшей модели — выбор зависит от уровня атлета, цели и временного горизонта. Главное правило: **сложность модели должна соответствовать тренировочному стажу**.

---

## Уровни планирования

```
МАКРОЦИКЛ   → Год (52 недели)
  └─ МЕЗОЦИКЛ   → 4–16 недель (обычно 4–6)
       └─ МИКРОЦИКЛ  → 1 неделя
            └─ ТРЕНИРОВОЧНЫЙ ДЕНЬ
```

---

## Модель 1: Линейная периодизация (LP)

**Суть:** Объём постепенно снижается, интенсивность растёт. Классический переход от высокого объёма/низкой интенсивности к низкому объёму/высокой интенсивности.

**Применять:**
- Новички (любая цель) — единственная оправданная модель
- Долгосрочное снижение веса (> 14 недель) — LP эффективнее DUP
- Военные и начинающие атлеты — снижение риска травм

**Схема мезоцикла LP:**
```
Нед 1: 4×12 @ 65% 1RM
Нед 2: 4×10 @ 70% 1RM
Нед 3: 4×8  @ 75% 1RM
Нед 4: 4×6  @ 80% 1RM
Нед 5: Делоад
```

**Слабые стороны:**
- Монотонный стимул → плато у тренированных быстро
- Инволюция ранее наработанных качеств (выносливость теряется при силовом блоке)
- Не подходит для длинного соревновательного сезона

---

## Модель 2: Волнообразная периодизация (DUP / WUP)

**Суть:** Диапазоны повторений и интенсивность меняются между тренировками (DUP) или между неделями (WUP). Нет монотонного раздражителя.

**Применять:**
- Средний и продвинутый уровень + гипертрофия
- Общая физическая форма
- Клиническое ожирение (DUP лучше LP для набора сухой массы)
- Краткосрочное снижение веса (< 8 недель)
- Снижение инсулинорезистентности у мужчин

**DUP — ротация за неделю (4 дня/нед):**
```
День 1 (Пн): 5×4–6  @ 85% 1RM   → Силовой стимул
День 2 (Вт): 4×8–12 @ 70% 1RM   → Гипертрофия
День 3 (Чт): 5×4–6  @ 85% 1RM   → Силовой стимул
День 4 (Пт): 3×13–20 @ 55% 1RM  → Метаболический объём
```

**Доказательная база:**
Colquhoun et al. (2018): DUP > LP для роста силы у тренированных атлетов (ES 0.61, p=0.05). Для новичков разницы нет (ES 0.06, p=0.67).

**Слабые стороны:**
- Требует хорошего восстановления для частой смены стимулов
- Планирование сложнее LP

## Модель 3: Блоковая периодизация (BP)

**Суть:** Последовательные мезоциклы-блоки с концентрированной нагрузкой на конкретное качество. Использует «остаточный тренировочный эффект» — качества сохраняются некоторое время после прекращения акцентированной тренировки.

**Три классических блока:**
```
БЛОК 1: Накопление (Accumulation)
  Цель: базовые качества, объём, техника
  Объём: высокий | Интенсивность: умеренная

БЛОК 2: Трансформация (Transmutation)
  Цель: специфическая работоспособность
  Объём: снижается | Интенсивность: растёт

БЛОК 3: Реализация (Realization)
  Цель: пик формы, максимальная сила/мощность
  Объём: низкий | Интенсивность: максимальная
```

**Применять:**
- Средний/продвинутый + развитие максимальной силы
- Подготовка к соревнованиям с фиксированной датой
- Преодоление молекулярной интерференции (AMPK vs mTOR)

**Преимущество:** Bartolomei et al. (2014) — BP даёт больший прирост взрывной мощности при **меньшем суммарном тоннаже**. Более энергоэффективна для силовых показателей.

**Физиологический эффект BP в выносливости** (велосипедисты, 12 нед):
- Объём эритроцитов: BP +10% vs традиционная тренировка
- Плотность капилляров: BP значительно выше
- VO2peak: BP +11.7% vs снижение на 4.1% в пороговой группе

---

## Модель 4: Блоковая + Пикинг (BP + Tapering)

**Для кого:** продвинутый атлет + соревнования с фиксированной датой.

**Tapering (сужение):**
```
За 2–3 недели до соревнований:
- Объём: снижается на 40–60%
- Интенсивность: СОХРАНЯЕТСЯ (80–95% 1RM)
- Частота: сохраняется или незначительно снижается

Цель: диссипация накопленной усталости при сохранении
всех нейромышечных адаптаций
```

---

## Модель 5: Реверсивная периодизация

**Суть:** Инверсия классики — начало с высокой интенсивности, постепенный рост объёма к соревнованиям.

**Применение:** ограниченное. Мета-анализ 2022 (11 исследований, 200 атлетов): не превосходит LP или BP по объективным показателям. Единственное доказанное преимущество — **психологическое** (мотивация 9.2/10 vs 8.0/10 у традиционных).

Применимо: короткие дисциплины (плавание 100м), когда монотония LP вызывает выгорание.

---

## Модели распределения интенсивности (для выносливости)

### Пирамидальная (PYR)
```
Z1 (< лактатного порога 1): ~80%
Z2 (между порогами 1 и 2):  ~15%
Z3 (> лактатного порога 2): ~5%
```
Применение: базовый общеподготовительный период, марафонцы.

### Пороговая (THR)
Акцент на Z2. Устарела — высокий риск парасимпатического угнетения, травматизма. Не рекомендуется как основная стратегия.

### Поляризованная (POL) ✅ Лучшая для элиты
```
Z1: 75–80% (восстановительная работа)
Z2: < 5%   (избегать «серой зоны»)
Z3: 15–20% (высокоинтенсивные интервалы)
```
Молекулярный механизм: экстремальные нагрузки Z3 активируют AMPK → PGC-1α → митохондриальный биогенез + MCT4 +133%.

**Контролируемое исследование:** элитные велосипедисты, POL vs THR: VO2peak +11.7% vs −4.1%.

**Оптимальная стратегия для года:**
```
Базовый период   → PYR (строим аэробную базу)
Специальный период → POL (максимизируем VO2max)
```

## Алгоритм выбора модели

```
Новичок (0–1 год)?
  ДА → LP (любая цель)

Средний/Продвинутый + цель = гипертрофия или общая форма?
  ДА → DUP

Средний/Продвинутый + цель = максимальная сила?
  ДА → BP

Продвинутый + соревнования + фиксированная дата?
  ДА → BP + Tapering

Похудение любой уровень?
  ДА → DUP с пониженным объёмом (не выше MAV)
  Долгосрочное (> 14 нед)? → рассмотреть LP

Циклические виды спорта + выносливость?
  ДА → PYR (базовый) → POL (специальный)
```

## Гибридный подход — современный консенсус 2025

Опросы ведущих специалистов: большинство используют **макроцикл по принципам BP**, внутри которого мезоциклы организованы **по волнообразному принципу DUP**.

Пример структуры для среднего атлета (набор массы):
```
Мезоцикл 1 (Нед 1–12):  Накопление → LP → DUP
  Задача: адаптация, техника, рост объёма
Мезоцикл 2 (Нед 13–24): Гипертрофия → DUP
  Задача: максимальный рост мышечной массы
Мезоцикл 3 (Нед 25–36): Сила → BP
  Задача: конвертация массы в силу
Мезоцикл 4 (Нед 37–52): Реализация → DUP
  Задача: поддержание, новый виток
```

## Методологические ограничения исследований

⚠️ Важно для критического мышления:

1. **Проблема уравнивания объёма:** большинство мета-анализов уравнивают тоннаж между LP и DUP, что нивелирует главное преимущество периодизации — стратегическое манипулирование объёмом
2. **Короткие сроки:** большинство РКИ длятся 6–12 недель. Эффекты блоковой периодизации разворачиваются месяцами
3. **Гетерогенность выборок:** данные новичков и элитных атлетов в одном мета-анализе дают статистический шум
4. **Путаница терминов:** «периодизация» и «вариативность» часто используются как синонимы — это ошибка
