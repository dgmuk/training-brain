## Правила формата (для тренера, удалить при публикации)

```
# Неделя N
**Период:** YYYY-MM-DD — YYYY-MM-DD
**Рекомендация:** Одна или две фразы о фокусе недели

## День N: Название
**Рекомендация дня:** Одна или две фразы

### Упражнение
[Видео](url)               ← только из exercise-library, без выдумок
- сеты x повт • в1/в2/в3 кг ← кол-во весов = кол-ву сетов
                              ← десятичные через точку: 22.5
                              ← собственный вес или резинка → 0

**Кардио:** строка        ← опционально в конце дня
---                       ← разделитель между днями
```

**Жёсткие правила формата:**

- Между `**Период:**` и `**Рекомендация:**` пустая строка
- После `**Рекомендация:**` идёт `**Контекст недели:**`, затем `**Красные флаги:**`
- После `**Красные флаги:**` для всех недель кроме первой идут три блока статистики прошлой недели в строгом порядке: `**Резюме прошлой недели:**`, `**Объём прошлой недели:**`, `**Самочувствие прошлой недели:**`
- Перед каждым `## День` пустая строка
- `### Упражнение` обязательно на отдельной строке
- `[Видео](url)` на следующей строке после названия, без пустой строки между ними
- Подходы с префикса `- `, далее `СЕТЫ x ПОВТ`, далее ` • `, далее веса через `/`, в конце ` кг`
- Количество весов через `/` равно количеству сетов
- Если сетов 3 а вес одинаковый, всё равно пиши `40/40/40`
- Если упражнение с собственным весом, пиши `0/0/0`
- После строки подходов — блок `**Альтернативы:**` (см. правило ниже)
- `---` отделяет день от следующего, последний `---` стоит перед чек-ином

**Правило блоков контекста (обязательно для каждой недели):**

Каждая неделя содержит три информационных блока сразу после `**Период:**`:

1. `**Рекомендация:**` — 1-2 предложения, фокус недели и целевой RIR.
2. `**Контекст недели:**` — 2-4 предложения простым языком: что происходит и зачем, как это вписывается в план, чего ожидать от ощущений в теле, что будет на следующей неделе. Клиент не должен чувствовать себя потерянным.
3. `**Красные флаги:**` — 2-3 конкретных сигнала, при которых клиент пишет тренеру немедленно, не дожидаясь чек-ина. Формат: «Если X, напиши сразу.»

**Правило статистики прошлой недели (обязательно для всех недель кроме первой в мезоцикле):**

После `**Красные флаги:**`, до первого `## День`, идут три блока в строгом порядке. Они генерируются на основе дневника прошлой недели и заголовка `## 📊 Итоговая статистика недели` из этого дневника. Цель блоков, чтобы клиент видел что его обратная связь услышана, а программа не шаблонная, а индивидуальная.

1. `**Резюме прошлой недели:**` — 3-5 предложений через запятую, общий обзор и мысли тренера. Что сделано и в каком объёме, какие технические победы видно по комментариям клиента, какие недочёты (работа на грани отказа в местах где этого не нужно, пропуски, отклонения от плана), как это влияет на текущую неделю. Без длинных тире, конкретно и по фактам, не общими словами.
2. `**Объём прошлой недели:**` — 2-4 предложения, объективная сводка по числам из дневника. Суммарный тоннаж за неделю, выполнение плана в процентах, средняя интенсивность по ключевым упражнениям относительно 1ПМ или RIR, сколько подходов и тренировок завершено из плановых, метки подходов (тяжело, дроп-сет) если были. Только цифры из дневника, без оценок и эмоций.
3. `**Самочувствие прошлой недели:**` — 2-4 предложения, обобщение строго со слов клиента. Средние значения сна, энергии, RPE за неделю, конкретные жалобы из заметок и какие из них учтены в текущей неделе (например, жалоба на поясницу учтена тем, что тяговое движение перенесено в начало дня).

Для **первой недели мезоцикла** все три блока статистики прошлой недели **отсутствуют**, потому что прошлой недели в этом мезоцикле ещё не было. Для калибровочной недели (Неделя 1, type calibration) их также нет. Для Недели 2 и далее блоки обязательны, парсер MetaSystem отображает их клиенту в начале страницы недели в свёрнутом виде.

Если в дневнике прошлой недели данных недостаточно для одного из блоков (например, клиент не оставил заметок и блок Самочувствие выходит пустым), напиши коротко по тому что есть, а не выдумывай. Минимум одно предложение в каждом блоке.

**Правило рекомендации дня (обязательно для каждого дня):**

`**Рекомендация дня:**` содержит 2-3 предложения: технические акценты на конкретные упражнения дня, явное указание времени отдыха между подходами в минутах, темп выполнения если важен. Не общие слова, а конкретика под этот день.

**Правило альтернатив (обязательно для каждого упражнения):**

К каждому упражнению добавляется блок из 3 альтернатив — на случай если у клиента нет возможности выполнить основное упражнение (нет тренажёра, дискомфорт, другая причина). Альтернативы подбираются по принципу проработки тех же мышечных групп, что и основное упражнение. Формат строго:

```
**Альтернативы:**
- Название альтернативы | [Видео](url) | N x M-K
- Название альтернативы | [Видео](url) | N x M-K
- Название альтернативы | [Видео](url) | N x M-K
```

- Названия альтернатив берутся только из [[../knowledge-base/exercises/exercise-library]]
- Ссылки на видео берутся из библиотеки, если ссылки нет — строка без `[Видео](...)`
- Количество сетов и повторений в альтернативе соответствует основному упражнению
- Блок `**Альтернативы:**` идёт сразу после строки подходов, без пустой строки между ними

**Стилистические правила (приоритет высший):**

- Никаких длинных тире как разделителей в `**Рекомендация:**` и `**Рекомендация дня:**`, только запятые и союзы (правило задано в `CLAUDE.md`)
- Длинное тире в строке `**Период:**` остаётся (это диапазон дат, не разделитель речи)
- Названия упражнений и ссылки `[Видео](url)` бери только из [[../knowledge-base/exercises/exercise-library]]
- Если упражнения нет в библиотеке, не выдумывай ссылку, оставь упражнение без `[Видео](...)` и сообщи тренеру в ответе
