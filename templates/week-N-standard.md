## Правила формата (для тренера, удалить при публикации)

```
# Неделя N
**Период:** YYYY-MM-DD — YYYY-MM-DD
**Резюме прошлой недели:** 2-3 предложения, итог в процентах попадания
**Рекомендация:** Одна или две фразы о фокусе недели
**Контекст недели:** 2-3 предложения, что меняется и зачем
**Красные флаги:** 2-3 пункта, формат «Если X, напиши сразу»
**По чек-ину:** опц., 1-3 предложения по ответам клиента
**Объём недели:** опц., 1-2 предложения о подходах
**Что меняем по сравнению с прошлой неделей:** 3-7 буллетов

## День N: Название
**Рекомендация дня:** 2-3 фразы

### Упражнение
[Видео](url)               ← только из exercise-library, без выдумок
- сеты x повт • в1/в2/в3 кг ← кол-во весов = кол-ву сетов

**Кардио:** строка        ← опционально в конце дня
---                       ← разделитель между днями
```

**Жёсткие правила формата:**

- Между `**Период:**` и `**Резюме прошлой недели:**` пустая строка
- `**Резюме прошлой недели:**` идёт первым из текстовых блоков (для нед 2+, в нед 1 его нет)
- Далее `**Рекомендация:**`, `**Контекст недели:**`, `**Красные флаги:**` обязательны
- `**По чек-ину:**` и `**Объём недели:**` опциональны, идут до первого `## День`
- `**Что меняем по сравнению с прошлой неделей:**` идёт последним из верхних блоков, до первого `## День`
- Перед каждым `## День` пустая строка
- `### Упражнение` обязательно на отдельной строке
- `[Видео](url)` на следующей строке после названия, без пустой строки между ними
- Подходы с префикса `- `, далее `СЕТЫ x ПОВТ`, далее ` • `, далее веса через `/`, в конце ` кг`
- Количество весов через `/` равно количеству сетов
- Если сетов 3 а вес одинаковый, всё равно пиши `40/40/40`
- Если упражнение с собственным весом, пиши `0/0/0`
- После строки подходов идёт блок `**Альтернативы:**` (см. правило ниже)
- `---` отделяет день от следующего, последний `---` стоит перед чек-ином

**Правило краткости текстовых блоков (приоритет высший):**

Все текстовые блоки в начале недели и в начале дня должны быть короткими и читаться человеком на ходу с телефона. Жёсткие лимиты:

| Блок | Максимум | Что писать |
|------|----------|------------|
| `**Резюме прошлой недели:**` | 3 предложения | Итог в процентах попадания, человек человеку |
| `**Рекомендация:**` | 2 предложения | Фокус недели, целевой RIR |
| `**Контекст недели:**` | 3 предложения | Что меняется и зачем, чего ждать в теле |
| `**Красные флаги:**` | 3 пункта | «Если X, напиши сразу» |
| `**По чек-ину:**` | 3 предложения | Кратко по ответам клиента, без анализа всей недели |
| `**Объём недели:**` | 2 предложения | Где добавили или убрали подходы |
| `**Что меняем:**` | до 7 пунктов | По одному на упражнение, без лишних слов |
| `**Рекомендация дня:**` | 3 предложения | Технические акценты, отдых, темп |

Запрещено:

- Длинные абзацы 5+ предложений в любом из верхних блоков, клиент это не прочитает на ходу
- Огромные таблицы сравнения «нед N → нед N+1» с колонками «план / факт / план / причина», вместо этого короткий маркированный список «**Что меняем**»
- Дублирование информации между `**Рекомендация:**` и `**Контекст недели:**`
- Перечисление каждого упражнения в `**Контекст недели:**`, для этого есть `**Что меняем**`

**Правило резюме прошлой недели (обязательно для нед 2+):**

`**Резюме прошлой недели:**` содержит 2-3 коротких предложения в стиле живого разговора тренер-клиент. Главное в нём, процент попадания по плану. Считается так:

1. Каждый выполненный подход относится в одну из трёх корзин:
   - **В плане**, если фактический вес попадает в плановый диапазон или равен плановому, и фактические повторения в плановом диапазоне.
   - **Выше плана**, если фактический вес выше планового или клиент сделал больше повторений чем верх диапазона при плановом весе. Это значит для клиента было слишком легко.
   - **Ниже плана**, если фактический вес ниже планового или повторений меньше чем низ диапазона. Это значит клиент забуксовал или вес был тяжелее чем нужно.
2. Считаем процент каждой корзины от общего числа выполненных подходов с фактом.
3. Округляем до 5%, чтобы не было «73.4%».
4. В предложении даём оценку: «хорошая динамика» если в плане 60%+, «отлично» если 75%+, «отстаёшь» если ниже 50% и больше половины ниже плана.

Примеры правильных формулировок:

- «На прошлой неделе 80% подходов попали в плановый диапазон, 15% оказались легче чем нужно, 5% ниже плана. Это хорошая динамика для второй недели мезоцикла, продолжаем накопление.»
- «По итогам недели 50% в плане, 40% выше плана, 10% ниже. Это означает что веса первой недели были занижены, теперь подвинул цифры вверх где запас был очевиден.»
- «Ты сделал 3 из 3 тренировок, 70% подходов попали в плановый коридор, 25% выше плана и 5% ниже. Хорошо двигаешься, на этой неделе добавляю интенсивность там где было слишком легко.»

Запрещено:

- Перечислять каждое упражнение в этом блоке, для этого есть `**Что меняем**`.
- Использовать длинные тире.
- Писать абзацы по 5+ предложений.

**Правило блоков контекста (обязательно для каждой недели):**

Каждая неделя содержит блоки сразу после `**Период:**`:

1. `**Резюме прошлой недели:**` обязателен для нед 2+, не пишется в нед 1 (нечего резюмировать).
2. `**Рекомендация:**` 1-2 предложения, фокус недели и целевой RIR.
3. `**Контекст недели:**` 2-3 предложения простым языком, что происходит и зачем, как это вписывается в план, чего ожидать от ощущений.
4. `**Красные флаги:**` 2-3 пункта, формат «Если X, напиши сразу».

Опциональные блоки той же зоны (если есть содержание):

5. `**По чек-ину:**` 1-3 предложения, краткая реакция тренера на текстовые ответы клиента (сон, суставы, заметки), не на проценты подходов (для них есть Резюме).
6. `**Объём недели:**` 1-2 предложения, где меняется количество подходов и почему.
7. `**Что меняем по сравнению с прошлой неделей:**` маркированный список 3-7 пунктов, по одному на ключевое изменение, формат: `- Упражнение, было/стало, причина в 3-4 словах`.

**Правило рекомендации дня (обязательно для каждого дня):**

`**Рекомендация дня:**` содержит 2-3 предложения: технические акценты на конкретные упражнения дня, явное указание времени отдыха между подходами в минутах, темп выполнения если важен. Не общие слова, а конкретика под этот день.

**Правило альтернатив (обязательно для каждого упражнения):**

К каждому упражнению добавляется блок из 3 альтернатив на случай если у клиента нет возможности выполнить основное упражнение (нет тренажёра, дискомфорт, другая причина). Альтернативы подбираются по принципу проработки тех же мышечных групп. Формат строго:

```
**Альтернативы:**
- Название альтернативы | [Видео](url) | N x M-K
- Название альтернативы | [Видео](url) | N x M-K
- Название альтернативы | [Видео](url) | N x M-K
```

- Названия альтернатив берутся только из [[../knowledge-base/exercises/exercise-library]]
- Ссылки на видео берутся из библиотеки, если ссылки нет, строка без `[Видео](...)`
- Количество сетов и повторений в альтернативе соответствует основному упражнению
- Блок `**Альтернативы:**` идёт сразу после строки подходов, без пустой строки между ними

**Стилистические правила (приоритет высший):**

- Никаких длинных тире как разделителей в `**Резюме прошлой недели:**`, `**Рекомендация:**`, `**Контекст недели:**`, `**Красные флаги:**`, `**По чек-ину:**`, `**Объём недели:**`, `**Что меняем:**`, `**Рекомендация дня:**`. Только запятые и союзы (правило задано в `CLAUDE.md`).
- Длинное тире в строке `**Период:**` остаётся (это диапазон дат, не разделитель речи).
- Названия упражнений и ссылки `[Видео](url)` бери только из [[../knowledge-base/exercises/exercise-library]].
- Если упражнения нет в библиотеке, не выдумывай ссылку, оставь упражнение без `[Видео](...)` и сообщи тренеру в ответе.
