## 🚨 ЖЁСТКИЙ ФОРМАТ файлов week-N (для парсера)

> Программа конвертирует week-N.md в HTML-страницу для клиента. **Любое отклонение от формата сломает парсинг.**

### Структура

```
# Неделя N
                                            ← пустая строка
**Период:** YYYY-MM-DD — YYYY-MM-DD
                                            ← пустая строка
**Рекомендация:** Текст рекомендации недели.
                                            ← пустая строка
## День N: Название дня
                                            ← пустая строка
**Рекомендация дня:** Текст рекомендации дня.
                                            ← пустая строка
### Название упражнения
[Видео](https://...)                        ← опц., БЕЗ пустой строки между названием и видео
- 4 x 10-12 • 20/22.5/25/30 кг
                                            ← пустая строка
### Следующее упражнение
- 3 x 10-12 • 50/55/55 кг
                                            ← пустая строка
**Кардио:** 15 мин ходьба (ЧСС 120-130)     ← опц., в конце дня
                                            ← пустая строка
---                                         ← разделитель между днями
                                            ← пустая строка
## День N+1: ...
```

### Формат строки подходов

```
- СЕТЫ x ПОВТ • ВЕС1/ВЕС2/.../ВЕСN кг
```

**Жёсткие правила:**

| Элемент | Правило |
|---------|---------|
| Префикс строки | `- ` (дефис + пробел) |
| Сеты × повторения | `4 x 10-12` (латинская `x`, диапазон через дефис) |
| Разделитель | ` • ` (пробел + bullet U+2022 + пробел) |
| Веса | через `/` без пробелов |
| Кол-во весов | **= количеству сетов** (4 сета → 4 веса) |
| Десятичные | через точку: `22.5`, не `22,5` |
| Собственный вес / резинка | `0` |
| Единица | ` кг` (через пробел, в конце) |
| Все цифры | арабские, без пробелов между разрядами |

### Что НЕ делать в week-N.md

- ❌ Не добавлять подзаголовки внутри дня (например, `### Разминка` — разминку описывай в Рекомендации дня)
- ❌ Не использовать таблицы для подходов (только список)
- ❌ Не вставлять колонки `Факт. вес / Факт. повт. / RIR` в таблицу подходов — поле для логирования генерится фронтендом
- ❌ Не использовать markdown-bold внутри строки подхода
- ❌ Не нумеровать упражнения (`1. Жим` — не нужно)
- ❌ Не указывать единицу повторений в строке (`- 4 x 10-12 повт •` — лишнее)
- ❌ Не писать «по 12 кг на каждую руку» — пиши вес одной гантели
- ❌ Не делать многострочное описание упражнения — только название + (опц.) видео + строка подходов

### Что МОЖНО

- ✅ Несколько `### Упражнение` подряд в одном дне
- ✅ Опускать `[Видео](url)` если ссылки нет
- ✅ Опускать `**Кардио:**` если кардио не назначено
- ✅ Любое количество дней (1–7)
- ✅ Текст в `**Рекомендация:**` и `**Рекомендация дня:**` — свободная форма

## 🪜 Особый случай: калибровочная неделя 1

В калибровке веса = `0/0/0/0`. Парсер по нулям детектирует калибровку и рисует на странице **поля ввода веса** для клиента.

В `**Рекомендация:**` обязательны слова **«Калибровочная»** или **«подбираем веса»** — это второй маркер для парсера.

В конце файла — единый блок «Алгоритм подбора веса» (см. [[week-1-calibration]]).

## 🔁 Workflow создания нового клиента

См. подробный пошаговый алгоритм: [[../knowledge-base/methodology/intake-workflow]]

Кратко:
1. Получить заполненную анкету → сохранить как `questionnaire-raw.md`
2. Заполнить `profile.md` из шаблона (включая расчёт персональных MEV/MAV/MRV)
3. Создать `macrocycle/overview.md` — 6-месячный план
4. Создать `mesocycle-1/overview.md` — план первого мезоцикла (для тренера, формат свободный)
5. Создать `mesocycle-1/week-1.md` из `week-1-calibration` — **БЕЗ весов**, в жёстком формате
6. После заполненного клиентом week-1 → создать `week-2.md` в `week-N-standard` формате с весами

## 📌 Принципы заполнения шаблонов

- **Все плейсхолдеры в формате `{{ПЛЕЙСХОЛДЕР}}`** — заменяй на реальные значения
- **Не удаляй ссылки `[[...]]`** в шаблонах профиля/мезо/макро (они скрепляют систему)
- **В файлах week-N.md ссылок `[[...]]` нет** — это документ для парсера/клиента, без вики-ссылок
- При отсутствии данных в профиле — пиши `—` или `не указано`, не оставляй пустоту
