## 📝 Протокол прогрессии

### Прогрессия интенсивности
- Каждые 2 недели целевой RIR снижается на 1
- Вес повышается, когда фактический RIR превышает плановый на 1+

### Правило повышения веса
```
Факт. RIR > Плановый на 1+ → +2.5–5 кг (крупные мышцы) / +1–2 кг (малые)
Факт. RIR = Плановый      → Вес не менять, добавить 1 повторение
Факт. RIR < Планового     → Снизить вес или убрать повторение
```

### Правило добавления подходов
```
Нед 1 → Нед 2: +1 подход на отстающие группы
Нед 2 → Нед 3: +1 подход на группы с RIR выше планового
Нед 3 → Нед 4: +1 подход везде (выход на MRV)
Нед 4 → Нед 5: ДЕЛОАД — −50% подходов, −20% веса
```

## 🚨 Маркеры для экстренной корректировки

*(см. [[../../../knowledge-base/recovery/recovery-markers]])*

При **2+ признаках одновременно** — стоп прогрессии, внеплановый делоад:

- Сон ниже 6/10 две недели подряд
- Энергия ниже 5/10 две недели подряд
- DOMS мешает следующей тренировке
- Рабочие веса не растут при RIR ≥ 3
- Любая боль в суставах (не мышечная DOMS)
- Падение мотивации, нарушение сна без причины
