## Файловая структура клиента

```
clients/{{имя}}/
├── README.md                    ← этот файл (навигация)
├── questionnaire-raw.md         ← оригинальная анкета (не редактировать)
├── profile.md                   ← обработанный профиль с расчётами
├── macrocycle/
│   ├── overview.md             ← 6-месячный план
│   ├── strategy.md             ← обоснование выбора моделей
│   └── progress-log.md         ← вес, замеры, PR по неделям
└── mesocycle-N/
    ├── overview.md             ← обзор мезоцикла для тренера
    ├── week-1.md               ← калибровка (без весов в Мезо 1)
    ├── week-2.md               ← с весами на основе week-1
    ├── week-3.md
    ├── week-4.md
    ├── week-5-deload.md
    └── checkin-week-N.md       ← (опц.) расширенный чек-ин
```

---

## Принцип работы

1. Клиент получает `week-N.md` → выполняет → заполняет лог и чек-ин
2. Тренер анализирует данные → создаёт `week-(N+1).md` с обновлёнными весами
3. После завершения мезоцикла → обновляется `macrocycle/progress-log.md` и создаётся следующий `mesocycle-(N+1)/`
4. `profile.md` обновляется при изменении веса, ограничений, тренировочных условий
