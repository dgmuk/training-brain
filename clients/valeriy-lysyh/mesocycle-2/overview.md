## 🎯 Цели мезоцикла

- **Главная:** Продолжить рост силы и массы после делоада Мезо 1, усилить присед и жим как отстающие движения, выйти на середину MAV по груди и квадрицепсам
- **Вспомогательная:** Закрепить онлайн-формат с фиксированными весами в приложении, сохранить осторожный протокол по ССЗ и возрасту
- **Система:** Full Body 3x (Пн / Ср / Пт), DUP-ротация, частота жима и приседа 2x/нед
- **Модель периодизации:** Блок накопления силы-гипертрофии, диапазон 6-12, RIR в пике не ниже 1-2
- **Формат:** Онлайн, клиент логирует веса в приложении, прогрессия по Схеме Б

## 📝 Протокол прогрессии (нед 7+)

```
Факт. RIR > Плановый на 1+ → +2.5 кг (главные) / +1-2 кг (изоляция)
Факт. RIR = Плановый      → Вес тот же, +1 повторение
Факт. RIR < Планового     → -5-10% веса
```

Возрастные поправки: прибавки меньше, чаще прогрессия по повторениям. [[../../../knowledge-base/methodology/aging-trainees]]

## 🚨 Маркеры для экстренной корректировки

При **2+ признаках одновременно** — стоп прогрессии, внеплановый делоад:

- Любые ССЗ-симптомы (одышка не по нагрузке, давление в груди, головокружение)
- Сон ниже 6/10 две недели подряд
- DOMS дольше 48 часов мешает следующей тренировке
- Падение рабочих весов 2+ тренировки подряд
- Боль в коленях на приседе или жиме ногами (не DOMS)

## 📈 Факт недели 6 (калибровка, для тренера)

| Показатель | Значение |
|------------|----------|
| Тренировки | 3/3 |
| Средняя энергия | ~6/10 (Д1: 8, Д2: 5, Д3: 5) |
| RPE | Д1: 7, Д2: 3, Д3: 3 |
| Чек-ин | сон 6, DOMS 4, энергия 5, мотивация 7, суставы норма, ССЗ-симптомов нет |
| Легче / тяжелее | бицепс штанга / становая |
| Ключевые веса | присед 120×8 RIR3; жим Пн 105×6-7 RIR2; тяга сидя 100; жим гант сидя 32; бицепс 45; трицепс 45; становая 140×8 (2/3); наклон 80×10; верт.тяга 81; гакк 75 (вместо жима ног Ср); махи 12; жим Пт 95×10-12 RIR1-2; жим ног 300; тяга штанги 110 (вместо гантели); наклон гант 34-36; молот 18-20; трицепс Пт 32-36 |

**Сигналы нед 6:**
1. Жим Пт: «перевести в режим 12 повторов» → 3×10-12 на 95 кг
2. Тяга Пт: комментарий «Тяга штанги в наклоне» + 110 кг → основное = Тяга штанги в наклоне
3. Добивка груди Пт: «Жим гантелей на наклонной, 3 подхода» → Жим гантелей лежа на наклонной 36×3 (приоритет над B=Pec-Deck)
4. Становая тяжелее всего, 3-й подход пустой → hold 140, довести 3 подхода
5. Ср: жим ногами заменён на гакк 75 (доступ/предпочтение), в плане оставлен жим ногами 280 (из калибровки Пт 300)
6. RIR 1 на жиме Пт и руках → без повышения этих весов, целевой RIR 2-3
7. Энергия 5 + сон 6 → прогрессия консервативная, без +кг на компаундах где RIR≤2

**Решения нед 7:** type standard; RIR 2-3; изоляция B; веса из калибровки; +1 сет жим/тяга/руки; становая hold; жим Пт 10-12; якорь тяги Пт = штанга; добивка = наклон гант.
