## Принцип работы (онлайн)

1. Клиент получает `week-N.md` в приложении, выполняет тренировки и логирует факт.
2. Тренер присылает заполненный дневник, на его основе строится следующая неделя по Схеме Б.
3. Неделя 6 калибровочная: веса `0/0/0`, клиент подбирает и фиксирует рабочие значения.
4. С недели 7 веса проставляются в плане, прогрессия по RIR и правилам мезоцикла.

## 🚨 Активные красные флаги

- **РПП (наблюдение тренера).** Питание и вес вне зоны работы тренера, в программе нет предписаний по похудению. Не давить на вес, не обсуждать дефицит.
- **Жёлтый свет по ССЗ.** ИМТ ~39 + возраст 47 + стрессовая работа. Протокол осторожный: без тестов 1ПМ, RIR не ниже 1-2 на главных, без задержки дыхания на усилии, LISS-кардио для сердца. См. [[../../knowledge-base/contraindications/cardiovascular]] и [[../../knowledge-base/methodology/aging-trainees]].
- **Подтягивания своим весом невозможны** при текущем весе. Вертикальная тяга только в тренажёре или гравитроне.
