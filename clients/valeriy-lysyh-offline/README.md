## Принцип работы (офлайн, План В)

1. Программа на 5 недель мезоцикла создаётся целиком, заранее.
2. Тренер ведёт клиента по программе на личных тренировках, рабочие веса выставляет на месте по RIR/RPE.
3. После завершения мезоцикла тренер присылает короткий отчёт по динамике (главные движения, рабочие веса, ощущения, давление, восстановление).
4. На основе отчёта строится следующий мезоцикл по всему 6-месячному макроциклу.

## 🚨 Активные красные флаги

- **РПП (наблюдение тренера).** Питание и вес вне зоны работы тренера, в программе нет предписаний по похудению. При необходимости питание ведёт профильный специалист по РПП. Не давить на вес, не обсуждать дефицит.
- **Жёлтый свет по ССЗ.** ИМТ ~39 + возраст 47 + стрессовая работа. Рекомендован медицинский скрининг. Протокол осторожный: без тестов 1ПМ в зале, RIR не ниже 1, без задержки дыхания (Вальсальва) на усилии, отдых увеличен, контроль самочувствия каждую тренировку. См. [[../../knowledge-base/contraindications/cardiovascular]] и [[../../knowledge-base/methodology/aging-trainees]].
- **Подтягивания своим весом невозможны** при текущем весе. Вертикальная тяга только в тренажёре или с компенсацией (гравитрон, резина), либо тяга верхнего блока.
