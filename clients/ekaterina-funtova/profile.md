## Режим программирования (читать ПЕРВЫМ)

```yaml
programming_mode: comfort_bank

```

**Полная методика:** [[../../knowledge-base/methodology/comfort-bank-rotation]]

### Что это значит одной фразой

Клиентка хочет **комфорт и разнообразие**, а не рост весов.  
Любая модель при Схеме Б **запрещает** себе стандартную эскалацию нагрузки из [[../../knowledge-base/methodology/progression-rules]].

### Жёсткие правила (нарушение = ошибка модели)

| # | Правило |
|---|---------|
| 1 | Плановый RIR **всегда 3–4**. Никогда не программировать RIR ниже **2**. |
| 2 | **Не** снижать RIR по фазам мезо (нет «пика» с RIR 0–1). |
| 3 | Вес по умолчанию **hold** (как в шаблоне банка / последнем факте). |
| 4 | Новизна = **другой шаблон недели** (W1–W4) или 1–2 замены из банка, **не** +5 кг. |
| 5 | Интенсификация (дроп-сеты, rest-pause, myo-reps, отказ) **запрещена**. |
| 6 | Не наращивать объём к MRV «по науке». Объём ≈ выбранный шаблон банка. |
| 7 | Имена упражнений и видео **только** из [[../../knowledge-base/exercises/exercise-library]]. |
| 8 | Формат `week-N.md` как у всех: шаблон [[../../templates/week-N-standard]], правила CLAUDE (разминка/заминка, альтернативы, без длинных тире в тексте). |
| 9 | Нумерация недель **непрерывная** на весь макро (`week: 5` в мезо 2, не `week: 1`). |
| 10 | При дневнике: ПРАВИЛО №5 (сигналы) + ПРАВИЛО №6 (adherence) обязательны в ответе тренеру. |

## Инструкция для ИИ: как создать week-(N+1)

> Этот блок, операционный контракт. Выполнять **по порядку**, без уточняющих вопросов, если дневник читается.

### Шаг 0. Проверка клиента

1. Frontmatter дневника / путь: `client_id = ekaterina-funtova`.
2. Открыть **этот** `profile.md` и убедиться: `programming_mode: comfort_bank`.
3. Открыть активный `mesocycle-N/overview.md` (сейчас мезо 2).
4. Если `programming_mode` отсутствует или другой, **остановиться** и спросить тренера (не перепутать с standard-клиентом).

### Шаг 1. Данные прошлой недели

1. Прочитать filled / дневник целиком (все дни, заметки, RIR, факт).
2. Составить **реестр сигналов** (ПРАВИЛО №5).
3. Посчитать **adherence** (ПРАВИЛО №6).
4. Процент попадания в план (для `**Резюме прошлой недели:**`) по ПРАВИЛУ №3.

### Шаг 2. Выбор шаблона банка (микроцикл = неделя)

| Continuous week | Template ID | Источник каркаса |
|-----------------|-------------|------------------|
| 1 | W1 | [[mesocycle-1/week-1]] |
| 2 | W2 | [[mesocycle-1/week-2]] |
| 3 | W3 | [[mesocycle-1/week-3]] |
| 4 | W4 | [[mesocycle-1/week-4]] |
| 5 | W1 | [[mesocycle-1/week-1]] (уже выдана как [[mesocycle-2/week-5]]) |
| 6 | W2 | [[mesocycle-1/week-2]] |
| 7 | W3 | [[mesocycle-1/week-3]] |
| 8 | W4 | [[mesocycle-1/week-4]] |
| 9–12 | W2 → W4 → W1 → W3 | те же файлы, другой порядок |
| 13+ | смотреть календарь в `mesocycle-N/overview.md` | обновить overview при новом мезо |

**Формула для нед 5–8:** `template = W(N - 4)`  
Пример: нед 6 → W2, нед 7 → W3.

### Шаг 3. Сборка каркаса week-(N+1)

1. Скопировать **все 3 дня** и упражнения из файла-шаблона банка.
2. Имена и URL видео сверить с library (не копировать устаревшее имя «на память»).
3. Сеты × повторы оставить как в шаблоне (если нет ease).
4. Веса:
   - **Hold** якоря шаблона, **или**
   - факт прошлой **той же** template-недели, если filled уже был и RIR 3–4.
5. На каждое упражнение: блок `**Альтернативы:**` × 3 из library (как в week-5).
6. В каждом дне: `**Рекомендация дня:**` + `**Разминка:**` + `**Заминка:**` (ПРАВИЛО №4).
7. Верхние блоки недели: лимиты ПРАВИЛА №3, без длинных тире (ПРАВИЛО №1).
8. YAML: `mesocycle`, continuous `week`, даты +7 дней от прошлой, `bank_template: W*`, `programming_mode: comfort_bank`.

### Шаг 4. Корректировка весов (вместо standard progression)

| Факт прошлой недели | Действие |
|---------------------|----------|
| RIR 3–4, повторы в плане, без жалоб | **Hold** |
| RIR ≥ 5 или «очень легко» | **Hold** + в `**Что меняем:**` можно отметить запас; +1–2.5 кг **только** если нет сигнала «не хочу тяжелее» |
| RIR = 2 ровно, все повторы | Hold или −1 шаг оборудования; в рекомендации напомнить про запас 3–4 |
| RIR ниже 2 / срыв / «тяжело» | минус 5–10% или проще упражнение из другого W на тот же паттерн |
| Боль сустава | замена, **не** повышать |
| «Скучно» / просит новизну | сменить template (если ещё не ротация) или 1–2 упражнения из другого W |
| Низкая энергия 2+ нед / adherence watch-talk | лёгкая неделя: тот же W, −10–15% или убрать 1 изоляцию в дне |

**Запрещено на этом шаге:**  
«раз RIR высокий, всегда +вес», «неделя пика → RIR 1», «+1 подход везде к MRV».

### Шаг 5. Запись файлов

1. Создать `clients/ekaterina-funtova/mesocycle-M/week-(N+1).md`.
2. Обновить `mesocycle-M/overview.md` (статус недели, attendance, template).
3. Обновить [[../index]] (колонка Статус).
4. При старте нового мезо: папка `mesocycle-(M+1)/`, continuous week **не** сбрасывать.

### Шаг 6. Ответ тренеру (обязательная структура)

```markdown
### Клиент
ekaterina-funtova | создана week-X | template WY | mesocycle Z

### Режим
comfort_bank (standard progression НЕ применялась)

### Комментарии и сигналы
- Обработано: …
- По просьбе: …
- По RIR/факту: …
- По боли: …
- Не применено и почему: …

### Adherence
- Статус: ok | watch | talk | critical
- Текущая: X/Y
- Прошлая: …
- Действие тренера: …

### Нагрузка
- Hold / ease / мелкий +вес (если был)
- Что изменили vs банк
```

## Цели и уровень

| Параметр | Значение |
|----------|----------|
| **Основная цель** | Комфортный регулярный тренинг, тонус, adherence, разнообразие |
| **Вторичная** | Поддержание мышечного тонуса без стресса от тяжёлых весов |

| **Дедлайн** | Нет |
| **Важность** | Высокая (комфорт = условие, что она ходит) |
| **Объективный уровень** | Новичок / низкий средний (по якорям банка) |
| **Опыт** | Есть завершённый ручной блок 4×3 под тренером |
| **Перерыв** | Не заявлен; return-after-break не применять без данных |

### Обоснование уровня

Рабочие веса умеренные (присед ~30 кг, RDL ~45 кг, гантели 3–5 кг), повторения высокие (12–15+), много тренажёров.  
Программируем **консервативно**, без допущения «она готова к тяжёлой прогрессии».

## Объёмные ориентиры (справочно, НЕ цель наращивания)

Для comfort_bank таблица MEV/MAV/MRV **не используется как лестница прогрессии**.  
Объём сессии ≈ шаблон банка. Потолок сессии по-прежнему: не >10–11 fractional sets на мышцу ([[../../knowledge-base/volume-landmarks/fractional-sets]]).

| Мышца | Ориентир MEV (жен. старт, справ.) | Политика для Екатерины |
|-------|----------------------------------|-------------------------|
| Грудные | ~6–8 | hold объёма банка |
| Спина | ~8–10 | hold |
| Квадрицепсы | ~8–9 | hold (ноги/ягодицы приоритет тонуса) |
| Бицепс бедра | ~6 | hold |
| Ягодичные | ~4–6 | hold / часто в банке |
| Ср./Зад. дельта | ~8 | hold |
| Бицепс / трицепс | ~6 | hold |
| Икры | ~8 | hold если есть в шаблоне |

Женская физиология (общий фон): [[../../knowledge-base/female-physiology/hypertrophy-women]]  
Шаги веса при редком повышении: мелкие (+1–2.5 кг), не «мужские» +5 на всём.
