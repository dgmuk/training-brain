## Режим программирования (критично)

```yaml
programming_mode: comfort_bank
target_rir: 3-4
rir_floor: 2
load_policy: hold_by_default
novelty_primary: week_bank_rotation
standard_progression: false
intensification: forbidden
```

**Полные правила:** [[../../knowledge-base/methodology/comfort-bank-rotation]]

### Жёсткие ограничения модели

1. Не применять стандартную эскалацию веса и снижение RIR по [[../../knowledge-base/methodology/progression-rules]].
2. Плановый RIR всегда 3–4; **никогда не программировать RIR ниже 2**.
3. Интенсификация (дропы, rest-pause, отказ) запрещена.
4. Новизна: ротация шаблонов W1–W4 и замены из банка, не «добавь 5 кг».
5. При RIR ≥ 5 по умолчанию hold + ротация, а не обязательный +вес.
6. При «тяжело» / RIR ниже 2: ease (минус 5–10% или проще вариант из банка).

## Цели и уровень

| Параметр | Значение |
|----------|----------|
| **Основная цель** | Комфортный регулярный тренинг, тонус, разнообразие |
| **Не цель** | Максимальная гипертрофия, силовые пики, работа в отказ |
| **Дедлайн** | Нет |
| **Объективный уровень** | Начальный–уверенный новичок / низкий средний (по весам банка: умеренные рабочие, высокий повторный диапазон) |
| **Опыт** | Уже прошла ≥1 блок из 4 недель под тренером |
| **Перерыв** | Нет данных о длинном перерыве |

## Тренировочные условия

| Параметр | Значение |
|----------|----------|
| **Оборудование** | Зал (штанга, Смит, гантели, блоки, рычаги, гравитрон, Bosu) |
| **Дней в неделю** | 3 |
| **Время сессии** | ~50–70 мин (оценка по объёму банка) |
| **Сплит** | 3× mixed / full-body bias (шаблоны банка, не строгий UL/PPL) |

**Обоснование:** 3 готовых дня на каждую неделю банка уже сбалансированы под зал и предпочтения клиентки; сплит не ломаем.

## Банк движений (якоря)

Повторяющиеся паттерны в W1–W4 (имена сверять с library при выдаче week):

| Паттерн | Примеры из банка |
|---------|------------------|
| Присед / ноги | Приседания со штангой, Приседания в тренажере Смита, Гоблет, плие с гирей |
| Hinge / задняя цепь | Румынская тяга со штангой, Румынская тяга в блоке, одноногие вариации |
| Ягодицы | Ягодичный мост со штангой, мост на одной ноге, разгибание бедра стоя |
| Тяга верха | Вертикальная тяга, гравитрон, рычажная тяга, горизонтальная тяга |
| Жим | Смит наклон, рычажный жим, гантели, брусья (грудь/трицепс) |
| Изоляция ног | Разведение/сведение ног, разгибание ног |
| Руки / дельты | Сгибания гантелей, разгибания блока, протяжка / высокая тяга, бабочка |
