## Инструкция ИИ: создать week-6 (пример шаблона действий)

1. Открыть [[../profile]] → подтвердить `comfort_bank`.  
2. Template = **W2** (таблица выше).  
3. Каркас = содержимое [[../mesocycle-1/week-2]] (3 дня, веса якоря).  
4. Если есть filled week-5: реестр сигналов + adherence; веса по таблице hold/ease (не standard +кг).  
5. Записать `mesocycle-2/week-6.md` с `week: 6`, `mesocycle: 2`, `bank_template: W2`.  
6. Полный формат: резюме, рекомендация, контекст, флаги, дни с разминкой/заминкой, альтернативы ×3, library.  
7. Обновить эту таблицу статусов + [[../../index]].  
8. Ответ тренеру: режим comfort_bank + сигналы + adherence.

То же для week-7 (W3) и week-8 (W4).

## Протокол нагрузки (мезо 2)

| Факт | Действие |
|------|----------|
| RIR 3–4, план закрыт | Hold |
| RIR ≥ 5 / «легко» | Hold + новизна; +1–2.5 кг только если ок |
| RIR ниже 2 / тяжело | −5–10% или вариант из другого W |
| Скучно | 1–2 упражнения из другого W (не чаще 1 раза в 2 нед) |
| Усталость 2+ нед | лёгкая: −10–15% или −1 изоляция |
| 1 пропуск | без удвоения объёма (adherence) |

**Запрещено:** пик RIR 0–1, дроп-сеты, «+подход везде», standard progression-rules.

**Ротация изоляции A/B:** режим `comfort_bank` (default A/B **выключен**).

## Маркеры экстренной корректировки

При 2+ признаках: ease, не «геройская» прогрессия:

- Энергия ≤5/10 две недели  
- Боль в суставе  
- RIR ниже 2 повторно  

- Мотивация низкая + пропуски → talk (ПРАВИЛО №6)

### Сигналы нед 5

1. RIR ниже целевого (3-4): на изоляции RIR 1-2 (обратные разведения RIR 1, французский жим RIR 1-2). Напомнить про запас 3-4.
2. Смит занят: заменила на жим гантелями наклон — допустимо, в week-6 пометка про замену.
3. Вертикальная тяга: сама добавила вес 20→27 кг, RIR 2-4. Хороший запас.
4. Adherence 2/3: День 3 не заполнен. Watch, следить.
5. Жалоб нет, энергия 7-8/10, RPE 7-9.
