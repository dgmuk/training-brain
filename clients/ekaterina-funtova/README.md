## Принцип работы (для тренера)

1. Клиентка получает `week-N.md` из GitHub/приложения.  
2. Выполняет, логирует filled.  
3. Тренер кидает дневник → модель читает **profile** → создаёт `week-(N+1)` в режиме **comfort_bank**.  
4. Веса hold/ease; новизна через W1–W4; RIR 3–4.  
5. Не ждать «как у всех» MEV→MRV.
