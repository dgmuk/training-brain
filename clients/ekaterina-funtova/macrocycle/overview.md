## Политика нагрузки на весь макро

| Параметр | Значение |
|----------|----------|
| Плановый RIR | 3–4 |
| Пол RIR | 2 |
| Вес | hold by default |
| Объём | ≈ шаблон банка, не лесенка к MRV |
| Интенсификация | запрещена |
| Силовые тесты 1RM | не планируются |
| Кардио-программа | не назначается (только разминка/заминка), пока цель comfort |

### Решения по факту (все мезо)

| Факт | Действие |
|------|----------|
| RIR 3–4 | Hold |
| RIR ≥ 5, «легко» | Hold + новизна; мелкий +вес только с согласия |
| RIR ниже 2 / тяжело | минус 5–10% или проще вариант из банка |
| Скучно | другой W / 1–2 упражнения |
| Усталость 2+ нед | лёгкая неделя −10–15% |

## Объём по мезоциклам

**Не** ведём таблицу «MEV → MRV пик».  
Справочно: объём каждой выдачи = объём выбранного W*.  
При миксе не превышать 10–11 fractional sets на мышцу за сессию.

| Мышца | Политика |
|-------|----------|
| Ягодичные / квадрицепс / бицепс бедра | Приоритет тонуса, hold |
| Спина | Hold |
| Грудные / дельты / руки | Hold, поддерживающий объём |
| Икры / кор | Как в шаблоне |

## Триггеры перепланирования макро

- Клиентка **просит** более силовую/гипертрофийную программу → сменить `programming_mode` только после явного ОК/тренера
- Травма 2+ нед → contraindications + упрощённый банк
- Пропажа 1+ мес → [[../../../knowledge-base/methodology/return-after-break]] (rebuild), не «как ни в чём не бывало»
- Attendance talk/critical 2+ цикла → minimalist-вариант или разговор (черновик в ответе)
