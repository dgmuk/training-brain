## Выбор модели

| Вопрос | Решение |
|--------|---------|
| Классический mass-gain / strength macro? | **Нет** |
| Модель | **Comfort Bank Rotation (CBR)** |
| Периодизация интенсивности | Плоская: RIR 3–4 постоянно |
| Периодизация новизны | Ротация порядка W1–W4 + точечный микс |
| Сплит | 3 дня / нед из банка (mixed full-body) |
| Почему | Клиентка явно не хочет больших весов и жёсткой нагрузки; adherence и комфорт важнее тоннажа |

---

## Почему не standard Schema A/B progression

1. Standard progression снижает RIR к 0–1 на пике мезо, это конфликт с её полом RIR ≥ 2.
2. Рост рабочих весов как KPI будет демотивировать.
3. Уже есть 4 рабочие недели: рациональнее крутить **проверенный** материал, чем строить «научный» мезо с нуля.
4. Женская гипертрофия-методика применима по технике и шагам веса, но **потолок агрессии** здесь отключён политикой comfort_bank.

## Долгосрочная логика (6+ месяцев)

| Фаза | Длительность | Что делаем |
|------|--------------|------------|
| Стабилизация в алгоритме | 4–8 нед | Выдача W1–W4 по календарю, сбор filled-дневников |
| Перетасовка | следующие 8–12 нед | Новый порядок банка, редкие точечные замены |
| Обновление банка | по запросу / 1 раз в квартал | 1 новый день или 2–3 новых упражнения из library вместо «устаревших», веса калибруем в комфорте |
| Смена цели | только если клиентка попросит | Тогда пересмотр programming_mode и возможен переход на soft hypertrophy (RIR 2–3, очень мелкие шаги) |

---

## KPI успеха (для тренера)

1. Attendance ≥ 70% большинство недель.
2. Субъективный комфорт в заметках (нет «слишком тяжело» две недели подряд).
3. Клиентка не просит «уберите веса» после выдачи.
4. Есть ощущение новизны без смены философии нагрузки.

Не KPI: рост 1RM, выход на MRV, отказные подходы.

## Риски

| Риск | Митигация |
|------|-----------|
| Стагнация мотивации от «одних и тех же весов» | Ротация порядка недель и микс 1–2 упражнений |
| Случайный уход модели в standard progression | Явный `programming_mode` в profile + блок в каждом overview |
| Слишком легко → скука | Мелкий +вес только с согласия; чаще новизна движением |
| Травма / боль | Ease + замена паттерна, не «потерпи» |
