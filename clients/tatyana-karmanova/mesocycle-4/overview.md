## Протокол прогрессии

```
Нед 16: вход после делоада, RIR 2-3, без компенсации пропущенного Д3
Нед 16 -> 17: +1 повтор или +1-2.5 кг только при полном плане и спокойной спине
Нед 17 -> 18: добавить подход только группам с хорошим RIR и без роста DOMS
Нед 18 -> 19: hold или +1 повтор, на ногах RIR не ниже 1-2
Нед 19 -> 20: делоад, -40-50% подходов, -10-20% веса, RIR 4-5
```

Правило спины: Румынская тяга выполняется только без боли до, во время и после подхода. При сохраняющемся дискомфорте использовать сгибание ног из альтернатив, не переносить вес автоматически.

## Сплит и якорные упражнения

### День 1, Full Body A

1. Жим ногами в тренажере, 4 x 10-12, RIR 2-3
2. Жим гантелей лежа на горизонтальной скамье, 3 x 8-12, RIR 2-3
3. Вертикальная тяга к груди средним хватом, 3 x 10-12, RIR 2-3
4. Сгибание ног в тренажере лежа, 3 x 10-15, RIR 2-3
5. Махи гантелей в стороны стоя, 3 x 12-15, RIR 2-3
6. Разгибание рук на верхнем блоке с канатом, 3 x 12-15, RIR 1-3

### День 2, Full Body B

1. Румынская тяга со штангой, 3 x 8-12, RIR 2-3, только без боли
2. Ягодичный мост со штангой, 3 x 10-12, RIR 2-3
3. Горизонтальная тяга в тренажере сидя, 3 x 10-12, RIR 2-3, refresh
4. Жим гантелей сидя нейтральный хват, 3 x 8-12, RIR 2-3
5. Face Pulls, 3 x 12-15, RIR 2-3
6. Сгибание рук на нижнем блоке с канатной рукоятью, 3 x 10-12, RIR 1-3

### День 3, Full Body C

1. Гоблет-приседания, 3 x 10-12, RIR 2-3
2. Жим гантелей лежа на наклонной скамье, 3 x 10-12, RIR 2-3
3. Вертикальная тяга блока узким хватом, 3 x 10-12, RIR 2-3
4. Ягодичный мост на полу, 3 x 12-15, RIR 2-3, refresh вместо гиперэкстензии
5. Сгибание ног сидя, 3 x 10-15, RIR 2-3
6. Подъемы на носки сидя в тренажере, 2 x 12-15, RIR 2-3
7. Разгибание рук на верхнем блоке, 3 x 12-15, RIR 1-3

## Питание и кардио

Для мезоцикла выхода держать ориентир 1900-2100 ккал и 140-160 г белка в день. LISS 2-4 раза в неделю по 25-40 минут, зона Z2, без HIIT, пока нет подтверждения по спине и энергии.

### Реестр сигналов

1. Спина не болела и не тянула при упражнениях. Сохраняем румынскую тягу по 35 кг, тягу с опорой и мост на полу. При возвращении дискомфорта на румынской тяге используем сгибание ног.
2. Суставы в порядке. Жим ногами и мост со штангой получают пробный шаг +2.5 кг в последнем подходе при хорошем самочувствии.
3. Судорог икр не было. Икры остаются на 45 кг, финальный RIR 2.
4. RPE третьего дня 10/10 и финальный RIR 1 на узкой тяге. Вес последнего подхода тяги снижен, остальной Д3 удерживаем.
5. При высоком RPE сохраняем 57 подходов на нед. 17. Плановое повышение объёма MEV+1 откладываем до чек-ина, переход к поддержанию остаётся по макроциклу.
6. Изоляция B рассчитана по факту B нед. 14-15 для тех же движений и слотов. Учитываем меньший объём нед. 15 при подборе стартовых весов.
