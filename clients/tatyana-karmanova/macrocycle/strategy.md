## Принятые решения

### Цель: fat-loss (не mass-gain, не pure comfort)

**Почему:** главная цель анкеты, похудение / % жира.  
Силовая нужна для **сохранения мышц** на дефиците, кардио LISS для доп. расхода и здоровья.  
Шаблон: [[../../../knowledge-base/macrocycle/fat-loss-template]] + [[../../../knowledge-base/fat-loss/programming]].

### programming_mode: soft_progression_fat_loss

**Почему не comfort_bank:** тренер явно разрешил мягкую прогрессию; клиентка не новичок, веса хорошие.  
**Почему не агрессивный peak RIR 0:** возраст 48, колени, дефицит, важность цели 6/10 (не «соревновательный срез»).

### Сплит: Full Body 3x

**Почему:** 3 дня/нед + fat-loss → максимальная частота стимула на крупные группы при ограниченном числе визитов.  
Дни A/B/C с разным акцентом (лёгкий DUP-оттенок):

| День | Акцент |
|------|--------|
| A | Квад (knee-safe) + горизонтальный жим + вертикальная тяга |
| B | Hinge / ягодицы + горизонтальная тяга + вертикальный жим |
| C | Смешанные ноги + upper volume + руки |

### Модель периодизации

- Внутри мезо: мягкий LP по весу/повторам (soft progression)  
- Между мезо: объём чуть выше старта предыдущего, **потолок нижняя–средняя MAV**  
- Обязательный делоад каждые 5-я неделя  
- Isolation A/B с нед 2 (после калибровки)

### Длина: ~20–24 недели (4–5 мезо) + выход

Достаточно для устойчивого −0.3–0.5 кг/нед без срыва.  
Нет жёсткого дедлайна события.

### Неделя 1: калибровка

Нет цифр 1RM в анкете. 0/0/0, она вносит рабочие.  
Дальше week-2+ с реальными весами и soft progression.

### Приоритеты

1. Сохранить рабочие веса на компаундах при дефиците  
2. Колени: безопасные паттерны, без ударки  
3. Белок + умеренный дефицит (питание хаотичное → якоря)  
4. LISS 2–4×/нед, без HIIT на старте  
5. Мягкий рост нагрузки, где RIR позволяет  

### Колени + возраст + женщина

| Фактор | Влияние |
|--------|---------|
| Колени | knee-safe selection, RIR на ногах не в отказ |
| 48 лет | MRV −10–15%, делоад обязателен, мелкие шаги |
| Женщина | чаще +повт., ноги/ягодицы переносят объём, верх не забывать |
| Регулярный цикл | при ПМС/лютеиновой: hold, не «сломать» план |

## Риски

| Риск | Митигация |
|------|-----------|
| Хаотичное питание | Белок 140–160 г, простые правила, не удваивать кардио |
| Рецидив коленей | ROM, замены, мониторинг 0–10 |
| Срыв мотивации 6/10 | Реалистичный темп, делоады, не «военный» дефицит |
| Потеря мышц на дефиците | Компаунды священны, soft progression весов |
| Модель уйдёт в comfort hold | profile: soft_progression_fat_loss явно |
