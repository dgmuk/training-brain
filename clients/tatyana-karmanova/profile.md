## Инструкция для ИИ: week-(N+1) (Схема Б)

### Шаг 0

1. `client_id = tatyana-karmanova`  
2. Открыть этот profile + активный `mesocycle-N/overview.md`  
3. Режим: **soft_progression_fat_loss**, не comfort_bank, не pure strength

### Шаг 1. Данные

- Весь filled, реестр сигналов (ПРАВИЛО №5), adherence (ПРАВИЛО №6)  
- Отдельно: жалобы на **колени** → knees-протокол, не повышать на проблемном движении  
- Лютеиновая / сильный ПМС (если отметит): не давить RIR, hold/ease

### Шаг 2. Прогрессия (мягкая)

| Факт | Действие |
|------|----------|
| RIR ≥ план+1, все повторы, колени ок | +1–2.5 кг (изоляция/гантели) или +2.5 кг (компаунд) **или** +1–2 повт. |
| RIR = план | +1 повт. в диапазоне, вес hold |
| RIR ниже плана / не добрала | hold или минус 2.5–5%, не удваивать объём |
| «Легко», но колено ныло | **не** +вес на ноги; замена/ROM |
| Энергия ≤4/10, сон плохой 2+ нед | hold объёма, RIR +1, см. recovery-autoregulation |
| Нед 4 мезо | не гнать RIR 0; пик **1–2** |
| Нед 5 | **делоад** MV, −40–50% подходов, −10–20% веса, RIR 4–5 |

Шаги веса женские/возрастные: чаще **повторы**, реже крупный +кг.  
Standard [[../../knowledge-base/methodology/progression-rules]] **применять**, но с потолком агрессии выше.

### Шаг 3. Объём

- Не лезть в персональный MRV на дефиците  
- Потолок мезо 1: **нижняя–средняя MAV**  
- При падении весов 2+ нед: сначала −объём, не −все веса подряд  
- Isolation A/B по overview

### Шаг 4. Колени (всегда)

- Нет deep ATG squat, тяжёлых выпадов вперёд, плио, спринтов  
- Предпочтение: жим ногами (контроль ROM), Смит/гоблет до параллели, RDL, мост, сгибания ног  
- Разгибания ног: лёгкий вес, без агрессивной полной экстензии  
- Кардио: вело / эллипс / плавание / ходьба; **бег** только если колени 0–2/10 и клиентка хочет  
- Прогрев коленей: 5–10 мин вело/эллипс в разминке (уже в стандарте)

### Шаг 5. Кардио (цель fat-loss)

В `week-N.md` **прописывать** кардио:

| Фаза | LISS | HIIT |
|------|------|------|
| Мезо 1 | 2–3× 25–35 мин Z2 | 0 |
| Мезо 2+ | 3–4× 30–40 мин Z2 | 0–1 только если колени тихие |

Формат: строка `**Кардио:**` в конце дня и/или отдельный день.

### Шаг 5b. Питание в каждой week-N (обязательно)

Блок `**Питание / калории:**` (2–3 предложения, форма **Вы**):

| Фаза | Ккал (ориентир) | Белок |
|------|-----------------|-------|
| Рабочие нед 1–4 мезо | **1700–1900** | **140–160 г** |
| Делоад (нед 5) | **1900–2100** (ближе к поддержке) | 140–160 г |
| Если вес стоит 2+ нед при хорошем adherence | −100–150 ккал или +LISS, не оба сразу | hold |
| Если сила падает + усталость | +100–200 ккал на 5–7 дней | hold |

Якорь поведения при хаотичном питании: белок в каждый приём, 3–4 приёма в день.

### Шаг 6. Формат

- library + альтернативы ×3  
- разминка/заминка каждый день  
- continuous `week`  
- frontmatter полный + `address_form: vy`  
- **весь клиентский текст на Вы**  
- `**Питание / калории:**` в каждой неделе  
- ответ тренеру: сигналы + adherence + колени + прогрессия soft + калории недели

### Обоснование уровня

Самооценка «средний» + стаж 3+ + стабильность + оценка тренера «веса хорошие».  
В анкете нет цифр 1RM → **неделя 1 калибровочная** (0/0/0), она вносит привычные рабочие. Дальше soft progression от факта.

Не программировать как новичка (MEV×0.7) и не как pro peak.

- Жим ногами, гоблет/Смит до комфортной глубины, RDL, ягодичный мост, сгибания ног
