**Главная цель:** Набор мышечной массы
**Дедлайн / событие:** Новый год 2027 (~2026-12-31)
**Стартовая дата:** 2026-05-19
**Финиш:** 2026-12-28

**Выбранная общая модель периодизации:** DUP (волнообразная) внутри каждого мезоцикла, прогрессия объёма между мезоциклами по принципу BP (блоковая).

**Сплит:** Full Body 3x (Пн / Ср / Пт), обоснование: [[strategy]]

**Ротация изоляции в мезоциклах:** default A/B (якорные компаунды стабильны, изоляция чередуется). Мезо 2: два fixed-слота у Дмитрия по здоровью локтя и просьбе клиента → [[../../../knowledge-base/methodology/isolation-rotation]]

## 🚨 Триггеры для перепланирования макроцикла

- Боли в плечах или локтях, требующие исключения движений 2+ нед
- Падение результатов 3+ нед подряд несмотря на делоад
- Резкое изменение жизненных обстоятельств
- Кардинальная смена цели клиента
