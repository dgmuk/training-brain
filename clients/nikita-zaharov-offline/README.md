## Принцип работы (офлайн, План В)

1. Программа на 5 недель мезоцикла создаётся целиком, заранее.
2. Тренер ведёт клиента по программе на личных тренировках, рабочие веса выставляет на месте по RIR.
3. После завершения мезоцикла тренер присылает короткий отчёт по динамике (главные движения, рабочие веса на пике, ощущения, состояние поясницы).
4. На основе отчёта строится следующий мезоцикл, и так далее по всему 6-месячному макроциклу.
