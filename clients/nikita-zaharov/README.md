## Принцип работы (онлайн)

1. Клиент получает `week-N.md` в приложении, выполняет тренировки и логирует факт.
2. Тренер присылает заполненный дневник, на его основе строится следующая неделя по Схеме Б.
3. Неделя 6 калибровочная: веса `0/0/0`, клиент подбирает и фиксирует рабочие значения.
4. С недели 7 веса проставляются в плане, прогрессия по RIR и правилам мезоцикла.
