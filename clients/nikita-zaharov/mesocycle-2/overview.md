## 🎯 Цели мезоцикла

- **Главная:** Продолжить рост грудных и трицепса после делоада Мезо 1, выйти на середину MAV по груди, усилить стабилизаторы в наклонном жиме
- **Вспомогательная:** Закрепить новый онлайн-формат с фиксированными весами в приложении, сохранить ноги и спину без перегруза поясницы
- **Система:** Upper-Lower-Upper (Пн / Ср / Пт), частота жима 2x/нед
- **Модель периодизации:** DUP внутри недели, силовой Пн (5-8 повт) и гипертрофийный Пт (8-12 повт)
- **Формат:** Онлайн, клиент логирует веса в приложении, прогрессия по Схеме Б

## 📝 Протокол прогрессии (нед 7+)

```
Факт. RIR > Плановый на 1+ → +2.5-5 кг (главные) / +1-2 кг (изоляция)
Факт. RIR = Плановый      → Вес тот же, +1 повторение
Факт. RIR < Планового     → -5-10% веса
```

> Подробнее: [[../../../knowledge-base/methodology/progression-rules]]

## 🚨 Маркеры для экстренной корректировки

При **2+ признаках одновременно** — стоп прогрессии, внеплановый делоад:

- Возврат дискомфорта в пояснице (боль больше 3/10)
- Боль в плечевом суставе на жиме (не DOMS)
- Боль в локтях на жиме, брусьях или разгибаниях
- Падение рабочих весов 2+ тренировки подряд
- Энергия ниже 5/10 две недели подряд

## 📈 Факт недели 6 (калибровка, для тренера)

| Показатель | Значение |
|------------|----------|
| Тренировки | 2/3 (Пн ✅, Ср ноги не заполнены, Пт ✅) |
| Attendance | 2/3 (67%), статус: **watch** (первая неделя ниже 70%, разговор не обязателен) |
| Чек-ин | сон 9, DOMS 6, энергия 7, мотивация 9 |
| Ключевые веса верх | жим 72.5×6-7 RIR2-3; тяга сидя 59; наклон гант 28 RIR1-2; брусья BW; бицепс 30; махи 12; трицепс 25; наклон штанга 60×10 RIR0 на 3-м; верт.тяга 61/59; кроссовер 9; «махи»→жим гант сидя 14; молот 14; трицепс Пт 20 |
| Ноги | факт пустой, калибровка не состоялась |

**Сигналы нед 6:**
1. Махи Пт: «Поменял на жим гантелей сидя. Далее будет это упражнение в этом цикле» → слот дельт Пн и Пт = Жим гантелей сидя 14 кг
2. Ноги не выполнены / не залогированы → по указанию тренера нед 7 снова 0/0/0 + алгоритм калибровки
3. Наклон 60 RIR 0 в конце → hold 60, акцент RIR 2-3
4. Наклон гант 28 RIR 1-2, трицепс/бицепс RIR 1-2 → hold весов, +объём без +кг
5. Брусья: «свой вес» → 0 кг

**Решения нед 7:** верх с весами; ноги калибровка 0; изоляция B на руках/fly/икрах/сгибании ног; дельты fixed = жим гант сидя (override ротации); +1 сет грудь/трицепс.
