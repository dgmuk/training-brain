## 📝 Протокол прогрессии

### Прогрессия интенсивности
- Каждые 2 недели целевой RIR снижается на 1
- Вес повышается, когда фактический RIR превышает плановый на 1+

### Правило повышения веса
```
Факт. RIR > Плановый на 1+ → +2.5-5 кг (крупные мышцы) / +1-2 кг (малые)
Факт. RIR = Плановый      → Вес не менять, добавить 1 повторение
Факт. RIR < Планового     → Снизить вес или убрать повторение
```

### Правило добавления подходов
```
Нед 6 → Нед 7: +1 подход на отстающие группы
Нед 7 → Нед 8: +1 подход на группы с RIR выше планового
Нед 8 → Нед 9: +1 подход везде (выход на MAV)
Нед 9 → Нед 10: ДЕЛОАД — -50% подходов, -20% веса
```

## 🚨 Маркеры для экстренной корректировки

При 2+ признаках одновременно — стоп прогрессии, внеплановый делоад:

- Боль в пояснице (не мышечная DOMS)
- Боль в плече при жимовых движениях
- Дискомфорт в локте при сгибаниях/разгибаниях
- Сон ниже 6/10 две недели подряд
- Энергия ниже 5/10 две недели подряд
- DOMS мешает следующей тренировке
- Рабочие веса не растут при RIR ≥ 3

## 📈 Факт недели 5 (для тренера)

| Показатель | Значение |
|------------|----------|
| Тренировки | 1/2 |
| Attendance | 1/2 (50%), статус: watch |
| Попадание в план | ~100% в плане (только День 1) |
| Средняя энергия | 8/10 (Д1) |
| Средний RPE | 5/10 (Д1) |
| Тоннаж | 6 930 кг (только Д1) |
| Ключевые веса Д1 | RDL 50×10 RIR4; наклон 50×10 RIR4; жим ног 70×10 RIR4; гравитрон 20×8 RIR3.5-4; махи 10×10 RIR4; трицепс 35×10 RIR4 |
| День 2 | не заполнено целиком |
| Комментарии | RDL: «хорошо пошло, думаю можно прибавить»; наклон: «нормально»; жим ног 👌🏻; энергия 8/10, «прекрасно» |
| Чек-ин | не заполнен |

**Сигналы нед 5:**
1. День 2 пропущен на делеаде → adherence watch, без компенсации объёмом
2. RIR 4 везде на Дне 1 при плане 4-5 → на мезо 2 стартовать с весов нед 5, RIR 3-4
3. RDL: «можно прибавить» → на мезо 2 RDL 55 кг
4. Наклон: стабильно 50-60 → на мезо 2 старт 55 кг
5. Жим ног: 70 на делеаде, в нед 4 было 90-100 → на мезо 2 старт 80-85 кг
6. Энергия 8/10 на делеаде → восстановление прошло хорошо, можно стартовать мезо 2

**Решения нед 6:** старт мезо 2, MEV+2, RIR 3-4, 3 подхода на упражнение; веса на основе нед 5 с лёгким повышением; приседания заменены на жим ногами окончательно; ротация изоляции A/B включена.
